CP26 - Technical Documentation

Wiki generated from a direct audit of the Community Patch 2026 (CP26) source code, compared against the base game Star Trek: Infinite (Stellaris engine). Written for future contributors to the mod: what CP26 changes, how, and where.

⚠ About the existing CHANGELOG.md
The repository's CHANGELOG.md stops at version 1.6.9 (2026-05-25). The mod is currently at 1.8.8 (2026-07-24, see descriptor.mod and the git history). Several major systems (the A500/synthetics arc, the Bajoran wormhole, V'Ger, Terok Nor, vassalization, complete quest trees, the Daystrom Institute) are not documented in the changelog. This page was built by reading the source code directly and diffing every overridden file against the vanilla installation - not by trusting existing documentation. Treat CHANGELOG.md as a partial history of the early versions only.

1. Overview

CP26 is a community overhaul for Star Trek: Infinite (1.0.7). It works through two distinct Paradox modding mechanisms:

Full replacement (replace_path)

43 vanilla files are entirely replaced by a modified CP26 copy (declared in descriptor.mod). The original vanilla file is completely ignored, so CP26 must reproduce all of its useful content in addition to its own changes.

Pure addition

Everything else (hundreds of files) is simply added on top of normal game loading: new events, species, quests, megastructures, and so on. Paradox automatically loads every recognized .txt/.gfx/.asset file in the standard folders - no need to declare them in descriptor.mod.

Naming conventions

Understanding file prefixes is the key to navigating the mod:

PrefixMeaning
hornblower_*Files from the base "Hornblower" mod (the foundation CP26 is built on) - appear in replace_path when modified
aa_*"Ambient/AI" - non-player-startable AI major powers (Ferengi, Gorn, Orion, Tholian) and their subsystems (government, civics, personalities, system init)
cp26_*CP26-original narrative/systemic content (quest arcs, megastructures, special projects)
zz_cp26_*CP26 patches, fine-tuning, or late additions - often bugfixes for vanilla/Hornblower content or balance tweaks
zz_mm_*Megastructures ported from a third-party "Mid-game Megastructures" mod (Dyson Swarm, Fusion Hub, Lifter)
00_*, 01_*, 02_*...Numeric prefix = Paradox load order (files load alphabetically within a folder)

The "stub + split" pattern

Several large vanilla files declared under replace_path have been reduced to a one-line comment (e.g. common/quest_tree_nodes/00_ufop_nodes.txt, common/solar_system_initializers/hornblower_initializers.txt, events/hornblower_game_start.txt). Their real content was split into dozens of individual files in the same folder (e.g. qt_ufop_a1.txt, game_start_101.txt). Paradox automatically loads every .txt in a folder, so this split works without any extra declaration - and lets new nodes/events be added without ever touching the replaced file.

For future modders: if you're looking for a UFOP quest node or a game_start event, don't search 00_ufop_nodes.txt or hornblower_game_start.txt - they're empty. Look for the matching qt_ufop_<name>.txt or game_start_<id>.txt file instead.

2. Replaced vanilla files (43 replace_path entries)

Every entry below comes from an actual diff between the CP26 file and its counterpart in the vanilla Steam install - not from reading the changelog.

Ship components

common/component_templates/00_hornblower_utilities_roles.txt balance

  • Officer upkeep cost of combat computers: -10 → 0 (no more officer upkeep).
  • size_restriction lists heavily expanded to include CP26's new hulls (Sovereign, Voyager, Ambassador, Constellation, Lantree, K'vort, Kamarag, Jach, Raptor, Praetor, Ferengi cruiser/battleship/titan, Gorn/Orion/Tholian).
  • ai_weight raised from 3 to 4 on several templates (stronger AI preference).

common/component_templates/00_hornblower_weapons_missiles.txt balance

  • Medium/large photon torpedoes (tier 2): alloy cost raised from tier-3 to tier-5, and a new tetryon cost added (now requires a strategic resource).

Country types

common/country_types/00_country_types.txt AI/balance

  • Merges the former zz_cp26_default_country_type.txt; adds ignores_warp_range = yes to the default type and about 20 mobile country types (paired with OUTPOST_WARP_RANGE_RADIUS = 0 in the defines - outposts no longer grant a warp-range bubble).
  • min_navy_for_wars: 0.01 → 0.14 (the AI waits for a larger navy fraction before declaring war).
  • New dynamic support-fleet scaling system (constructors/science ships/colonizers) driven by cp26_empire_size_small/medium/large/huge flags, set yearly by an AI pulse based on planet count - replaces vanilla's static bounds.
  • Base support-fleet counts roughly halved (e.g. 50→35, 100→55), offset by the new dynamic scaling.

common/country_types/03_country_types_megacorp.txt - minor addition of the same ignores_warp_range flag.

Diplomacy

common/diplomatic_actions/00_actions.txt & 00_hornblower_actions.txt new system

  • Systematic widening of triggers to include CP26's new country types: is_country_type = contender / is_ferengi_empire / is_gorn_hegemony / is_orion_syndicate - these empires can now use standard diplomatic actions previously gated to the default type only.
  • A Ferengi-specific branch is added to an intel-sharing action (100 intel, open borders for 3600 days, survey of owned + subject planets).
  • Vassalization fully rewritten: the vanilla action_start_puppet_state_process action (requiring an envoy) is replaced by a CP26 system with no envoy requirement, custom tooltips (CP26_VASSALIZATION_PENDING), AI gating (cooldown, relative power, planet count, no federation/defensive pact/guarantee, no recent target, 50+ trust), cp26_vassalization_pending_actor/target flags, fires country_event = cp26_vassalization.1, 3-year AI cooldown after an offer.
  • New action action_cp26_offer_war_goal_peace: a wartime negotiated-peace proposal (cp26_vassalization.6).
  • action_support_independence, action_break_support, action_release_subject, action_liberate_subject, action_request_subject_liberation moved here and rewritten to work on is_regular_empire subjects, not just vanilla's minor/occupied ones.

Game rules

common/game_rules/00_rules.txt

  • The new contender country type (AI rival majors - Ferengi/Gorn/Orion) is treated like default in roughly a dozen game rules (colonization, war rules...).

Ships & designs

common/global_ship_designs/hornblower_designs.txt

  • The "Enterprise Sovereign" event ship design is significantly modernized (upgraded reactor, weapons, shields, hull, sensor components).

common/ship_sizes/00_ship_sizes.txt fleet cap

  • All military hulls (corvette through titan) gain a possible_construction check tied to cp26_under_reduced_fleet_military_cap - enforces CP26's reduced military fleet cap (~36 ships, referenced in the design notes as CP26_SHIP_FLEET_CAP_SYSTEM).
  • Titan: size_multiplier 16 → 14.
  • Science/constructor ships: hard per-empire cap empire_limit = { base = 3 max = 3 } (previously uncapped/soft).
  • Transport hull: gains ignores_warp_range = yes and +1 hyperlane range.

common/ship_sizes/21_hornblower_sizes.txt

  • size_multiplier rebalancing per class: Miranda 2→3, Intrepid 3→4, Galaxy 8→7, Sovereign 13→9, Bird-of-Prey 2→1, K'tinga 5→4, Vorcha 8→6, Neghvar 13→9, Valdore 5→7.
  • Intrepid: prerequisite changed from tech_destroyer_unlock to a dedicated tech_intrepid_unlock.
  • The California class was moved out into a separate CP26 file, outside the replace_path scope.

Name lists

common/name_lists/{CRD1,KLG1,RML1,UFP1}.txt

  • Adds a previously-missing generic name pool (a latent vanilla bug); deduplicates roughly 14 repeated copies of the same name block per file - mostly a data-hygiene cleanup rather than new content.

Policies & pop jobs

common/policies/00_policies.txt

  • Hard-coded species checks (is_ufop/klingon/romulan/cardassian) are systematically replaced with is_country_type = default OR contender plus is_minor/is_major guards - makes policies available to the new empires (Ferengi, Gorn, Orion, Tholian, Breen), which were silently excluded before.

common/pop_jobs/10{0,1,2,3,4}_hornblower_*_jobs.txt (5 files, one per major faction)

  • Consistent pattern: unity output of admin/specialist jobs trimmed about 20%; exists = owner/planet guards added to prevent script errors during galaxy generation.

Quest tree roots

common/quest_tree_nodes/00_cardassian_nodes.txt / 00_ufop_nodes.txt - reduced to stubs (see the stub+split pattern).

  • Cardassian: 15 vanilla nodes extracted verbatim into individual files; targeted fixes (invalid scope switches, diplomacy thresholds 2→4, target systems Sheva/Setlik instead of Denobula/Cordian).
  • UFOP: 27 vanilla nodes extracted, plus 4 brand-new nodes (qt_ufop_cerritos_lower_decks, upgrade_enterprise_odyssey, upgrade_utopia_planitia_a500, upgrade_voyager_lamarr). The Neutral Zone grows from 2 to about 11 systems; several thresholds loosened or tightened (e.g. battles ≥3→≥1, academies ≥8→≥6).

Ambient visual effects

Solar system initializers

  • Romulan border systems reassigned (Devron/Galador/Khitomer → Cheron/Dewa/Glintara/Hobus).
  • New systems for the AI factions: Ferengi, Gorn, Orion, Tholian, Megacorp caravaneers, Elaurian curators.
  • zone_rom_ufop/: 13 files implementing the expanded Federation-Romulan Neutral Zone (versus 4 systems in vanilla).

misc_system_initializers.txt - 19 planets reclassified as rl_unhabitable_planets.

Special projects

Replaced events

events/hornblower_colony_events.txt - Ferengi dialogue options added; scope fixes (an event fired from an invalid planet scope).

events/hornblower_country_events.txt (the largest file) -

  • Removes a punitive vanilla outcome (killing a random Romulan homeworld pop).
  • Several spawned fleet sizes reduced.
  • Adds Ferengi branches and generic fallback text for factions vanilla didn't account for.
  • About 5 events are hard-disabled (trigger = { always = no }, comment "CP26 2026-05-15 PERF: emergency runtime disable during freeze hunt") - an emergency fix for a freeze/performance bug, with a proper fix still pending.
  • California/Cerritos (Lower Decks) content migrated from a vanilla DLC-ownership check to a dedicated CP26 tech (tech_cp26_california_unlock).

events/hornblower_game_start.txt - a stub (see the stub+split pattern), split into game_start_101.txt through 280.txt.

events/game_start.txt - bootstraps the major-power targets as global event targets right away; new cp26_start_balance.1 balance tick in 2346; fixes a documented construction-queue crash (CP26_CONSTRUCTION_QUEUE_CRASH_FIX.txt); expanded Rura Penthe logic (create vs. transfer colony); many defensive exists = event_target guards.

events/hornblower_borg_crisis_events.txt + common/event_chains/00_hornblower_borg_crisis_chains.txt - a "Janeway Gambit" counter system (max 3 steps) wired into the event flow; reactivates the dormant borg_crisis_end_the_freed chain.

events/hornblower_pirate_events.txt - nearly identical, adds a cp26_no_pirates global flag for a full pirate-spawn toggle.

Interface

interface/outliner.gui - purely visual row-height tuning (no functional changes).

3. New factions & species

CP26 adds 4 major AI "ambient" powers (not player-startable, but active from galaxy generation onward) and about twenty prescripted minor civilizations, plus additional colonizable peoples (Denobulans, Remans, Risians...).

Ferengi Alliance playable

  • Species class: AAFERENGI (common/species_classes/aa_ferengi_species.txt), biological archetype.
  • Government: civics civic_ferengi_rules_of_acquisition, civic_ferengi_grand_nagus; authority auth_dictatorial_ferengi; government type gov_social_autocracy_ferengi.
  • Traits: trait_eye_for_business_ferengi, trait_traditionalists_ferengi.
  • AI personality: cp26_grand_nagus_merchants.
  • Playable nation: prescripted_countries/_04_ferengi.txt - fanatic materialist + xenophile ethics, home system "Ferenginar".
  • Game-start bring-up: events/aa_ferengi_start_events.txt (colonizes the flagged capital, 16 pops, starting fleet, opens contact with Cardassia/Tholia).
  • Dedicated economy: "Consortium" buildings (common/buildings/cp26_ferengi_buildings.txt), trade hub network (megastructures, see §7), "Rules of Acquisition" quest chain (10 nodes, see §5).

Gorn Hegemony AI

  • Class: AAGORN. Civics civic_gorn_predatory, civic_gorn_supremacy.
  • AI personality: hegemonic_imperialists_gorn, tuned so colony spending stays high enough for the Gorn to keep expanding despite their militarist bent.
  • Portraits: gfx/portraits/portraits/portraits_gorn.txt - no more generic Stellaris uniforms (clothes_selector = "no_texture").
  • Home systems: Galdonterre, Cestus, Finibus.
  • Hulls: Makar, Ddraig, Sarath, Balaur, Vazkoth, Hegemony Bulwark, Kethar Command (common/technology/cp26_gorn_orion_hull_tech.txt).

Orion Syndicate AI

  • Class: AAORION. Civics civic_orion_matriarchs, civic_orion_competition.
  • Home systems: Orion, Verex.
  • Hulls: Interceptor, Wanderer, Corsair, Marauder, Dreadnought, Emerald Citadel, Black Ledger.
  • Related content: optional Nausicaan marauders (events/cp26_nausicaan_marauder_spawn.txt, off by default, toggled via the start-of-game options popup).

Tholian Assembly AI

  • Class: AATHOLIAN. Civics civic_tholian_isolationism, civic_tholian_webspinners.
  • Traits: trait_tholian_crystalline, trait_tholian_disciplined, trait_tholian_prudent.
  • Home systems: Tholia, Berellium.
  • Ready Room: interface/aa_gorn_stuff.gfx - missing sprites added for the _01 alias (contact room lookup).

4. Diplomacy & vassalization

Beyond the diplomatic action menu itself (see §2), CP26 adds new structural systems:

  • common/casus_belli/zz_cp26_contender_casus_belli.txt - cb_claim, cb_humiliation, cb_humiliation_animosity, cb_subjugation, cb_cp26_forced_occupation: extends standard CBs to contender-type countries.
  • common/war_goals/zz_cp26_subjugation_war_goals.txt - wg_subjugation: restores war-based vassalization (peace offers: status quo/surrender/demand surrender/neutral zone, set_subject_of on acceptance).
  • common/war_goals/zz_cp26_forced_occupation_war_goals.txt - wg_cp26_forced_occupation.
  • common/on_actions/zz_cp26_vassalization_on_actions.txt - new hooks: on_becoming_subject, on_subject_change, on_releasing_subject, on_subject_integrated, on_assimilation_completed.
  • events/zz_cp26_vassalization_events.txt (ns cp26_vassalization) - keeps Liberation War CBs in sync for regular empires that become subjects.
  • events/cp26_integration_events.txt (ns cp26_integration) - post-integration cleanup (THIS = overlord, FROM = integrated subject).
  • events/zz_cp26_war_negotiation_events.txt + common/edicts/zz_cp26_war_negotiation_edicts.txt (cp26_open_war_negotiation) - a new negotiated-peace/edict mechanic during wars.
  • events/zz_cp26_war_access_events.txt + common/on_actions/zz_cp26_war_access_on_actions.txt - wartime military access handling.
  • Opinion modifiers: common/opinion_modifiers/zz_cp26_ferengi_cardassian_opinions.txt, cp26_bajor_opinions.txt (see the Bajor arc below).

9. For future contributors

  • Never edit a vanilla file directly in the game folder - every change must go through a CP26 file, either via replace_path (the whole file is replaced, declared in descriptor.mod) or as a standalone additive file.
  • Before searching a "root" file (00_ufop_nodes.txt, hornblower_initializers.txt, hornblower_game_start.txt), check whether it's been reduced to a stub - see the stub+split pattern in §1.
  • Follow the existing naming prefixes (§1) to stay consistent: cp26_* for new narrative content, zz_cp26_* for late patches/tuning.
  • CHANGELOG.md is behind - if you update it, verify the actual code state first (as this page did) rather than trusting the latest entries.
  • Test scope guards (exists = owner/planet/event_target:...) - several CP26 fixes documented above exist purely to avoid scope-context errors caught in error.log. This pattern is common in the mod and should be reused for new content.
  • Watch for performance regressions: some events have been hard-disabled mid-development (hornblower_country_events.txt, §2) after causing game freezes. Test new pulses/periodic events on long-running games before shipping them.
