CP26 - Documentation technique

Wiki genere par audit direct du code source de Community Patch 2026 (CP26), compare au jeu de base Star Trek: Infinite (moteur Stellaris). Redige pour les futurs contributeurs du mod : que modifie CP26, comment, et ou.

⚠ A propos du CHANGELOG.md existant
Le fichier CHANGELOG.md du depot s'arrete a la version 1.6.9 (25 mai 2026). Le mod est actuellement en 1.8.8 (24 juillet 2026, voir descriptor.mod et l'historique git). De nombreux systemes majeurs (arc A500/synthetiques, trou de ver bajoran, V'Ger, Terok Nor, vassalisation, arbres de quetes complets, Institut Daystrom) ne sont pas documentes dans le changelog. Cette page a ete construite en lisant directement le code source et en diffant chaque fichier remplace contre l'installation vanilla du jeu - pas en se fiant a la documentation existante. Considerez le CHANGELOG.md comme un historique partiel des premieres versions seulement.

1. Vue d'ensemble

CP26 est un overhaul communautaire pour Star Trek: Infinite (1.0.7). Il agit selon deux mecanismes Paradox distincts :

Remplacement complet (replace_path)

43 fichiers vanilla sont entierement remplaces par une copie modifiee de CP26 (declares dans descriptor.mod). Le fichier vanilla original est totalement ignore ; CP26 doit repliquer tout son contenu utile en plus de ses propres modifications.

Addition pure

Tout le reste (des centaines de fichiers) s'ajoute simplement au chargement normal du jeu : nouveaux evenements, especes, quetes, megastructures, etc. Paradox charge automatiquement tout fichier .txt/.gfx/.asset present dans les dossiers reconnus - pas besoin de les declarer dans descriptor.mod.

Conventions de nommage

Comprendre les prefixes de fichiers est la cle pour naviguer dans le mod :

PrefixeSignification
hornblower_*Fichiers du mod de base "Hornblower" (la fondation sur laquelle CP26 est construit) - presents dans replace_path quand modifies
aa_*"Ambient/AI" - factions IA non jouables au demarrage (Ferengi, Gorn, Orion, Tholian) et leurs sous-systemes (gouvernement, civics, personnalites, init de systeme)
cp26_*Contenu narratif/systemique original de CP26 (arcs de quete, megastructures, projets speciaux)
zz_cp26_*Correctifs, reglages fins ou ajouts tardifs de CP26 - souvent des fixes de bugs vanilla/Hornblower ou des reglages d'equilibrage
zz_mm_*Megastructures portees depuis un mod tiers "Mid-game Megastructures" (Dyson Swarm, Fusion Hub, Lifter)
00_*, 01_*, 02_*...Prefixe numerique = ordre de chargement Paradox (les fichiers se chargent par ordre alphabetique dans un dossier)

Le motif "stub + split"

Plusieurs fichiers vanilla volumineux declares en replace_path ont ete reduits a un simple commentaire d'une ligne (ex. common/quest_tree_nodes/00_ufop_nodes.txt, common/solar_system_initializers/hornblower_initializers.txt, events/hornblower_game_start.txt). Leur contenu reel a ete eclate en dizaines de fichiers individuels dans le meme dossier (ex. qt_ufop_a1.txt, game_start_101.txt). Paradox charge automatiquement tous les .txt d'un dossier, donc ce decoupage fonctionne sans declaration supplementaire - et permet d'ajouter de nouveaux noeuds/evenements sans jamais toucher au fichier remplace.

Pour un futur modder : si vous cherchez le contenu d'un noeud de quete UFOP ou d'un evenement game_start, ne cherchez pas dans 00_ufop_nodes.txt ou hornblower_game_start.txt - ils sont vides. Cherchez le fichier qt_ufop_<nom>.txt ou game_start_<id>.txt correspondant.

2. Fichiers vanilla remplaces (43 entrees replace_path)

Chaque entree ci-dessous provient d'un diff reel entre le fichier CP26 et son equivalent dans l'installation Steam vanilla - pas d'une lecture du changelog.

Composants de vaisseaux

common/component_templates/00_hornblower_utilities_roles.txt equilibrage

  • Cout en officiers des ordinateurs de combat : -10 → 0 (plus d'upkeep officier).
  • Listes size_restriction etendues a tous les nouveaux hulls CP26 (Sovereign, Voyager, Ambassador, Constellation, Lantree, K'vort, Kamarag, Jach, Raptor, Praetor, Ferengi cruiser/battleship/titan, Gorn/Orion/Tholian).
  • ai_weight releve de 3 a 4 sur plusieurs templates (preference IA accrue).

  • Torpilles a photons moyennes/larges (tier 2) : cout en alliages releve de tier 3 a tier 5, ajout d'un cout en tetryons (ressource strategique desormais requise).

Types de pays

common/country_types/00_country_types.txt IA/equilibrage

  • Fusionne l'ancien zz_cp26_default_country_type.txt ; ajoute ignores_warp_range = yes au type default et a une vingtaine de types mobiles (couple a OUTPOST_WARP_RANGE_RADIUS = 0 dans les defines - les avant-postes n'accordent plus de bulle de portee warp).
  • min_navy_for_wars : 0.01 → 0.14 (l'IA attend une flotte plus developpee avant de declarer la guerre).
  • Nouveau systeme d'echelle dynamique de flotte de soutien (constructeurs/scientifiques/colonisateurs) pilote par les flags cp26_empire_size_small/medium/large/huge, poses annuellement par un pulse IA selon le nombre de planetes - remplace les bornes statiques vanilla.
  • Effectifs de base de flotte de soutien reduits d'environ moitie (ex. 50→35, 100→55), compenses par le nouveau scaling dynamique.

common/country_types/03_country_types_megacorp.txt - ajout mineur du meme flag ignores_warp_range.

Diplomatie

common/diplomatic_actions/00_actions.txt & 00_hornblower_actions.txt nouveau systeme

  • Elargissement systematique des triggers pour inclure les nouveaux types de pays CP26 : is_country_type = contender / is_ferengi_empire / is_gorn_hegemony / is_orion_syndicate - ces empires peuvent desormais utiliser les actions diplomatiques standard, auparavant reservees au type default.
  • Branche Ferengi ajoutee a une action de partage de renseignement (100 intel, frontieres ouvertes 3600 jours, survol des planetes possedees + sujettes).
  • Systeme de vassalisation entierement reecrit : l'action vanilla action_start_puppet_state_process (necessitant un envoye) est remplacee par un systeme CP26 sans envoye, avec tooltips custom (CP26_VASSALIZATION_PENDING), portes IA (cooldown, puissance relative, nombre de planetes, absence de federation/pacte defensif/garantie, cible recente, confiance superieure a 50), flags cp26_vassalization_pending_actor/target, declenche country_event = cp26_vassalization.1, cooldown IA de 3 ans apres une offre.
  • Nouvelle action action_cp26_offer_war_goal_peace : proposition de paix negociee en cours de guerre (cp26_vassalization.6).
  • Actions action_support_independence, action_break_support, action_release_subject, action_liberate_subject, action_request_subject_liberation deplacees et reecrites pour fonctionner sur des sujets is_regular_empire, pas seulement les mineurs/occupes vanilla.

3. Nouvelles factions & especes

CP26 ajoute 4 grandes puissances IA "ambiantes" (non jouables au demarrage joueur, mais actives des la generation de galaxie) et une vingtaine de civilisations mineures pre-scriptees, en plus de peuples colonisables additionnels (Denobulans, Remans, Risians...).

Alliance Ferengi jouable

  • Classe d'espece : AAFERENGI (common/species_classes/aa_ferengi_species.txt), archetype biologique.
  • Gouvernement : civics civic_ferengi_rules_of_acquisition, civic_ferengi_grand_nagus ; autorite auth_dictatorial_ferengi ; type de gouvernement gov_social_autocracy_ferengi.
  • Traits : trait_eye_for_business_ferengi, trait_traditionalists_ferengi.
  • Personnalite IA : cp26_grand_nagus_merchants.
  • Nation jouable : prescripted_countries/_04_ferengi.txt - ethique fanatique materialiste + xenophile, systeme d'origine "Ferenginar".
  • Mise en place de partie : events/aa_ferengi_start_events.txt (colonise la capitale flaggee, 16 pops, flotte de depart, ouvre le contact avec Cardassia/Tholia).
  • Economie dediee : batiments "Consortium" (common/buildings/cp26_ferengi_buildings.txt), reseau de hubs commerciaux (megastructures, voir §7), quete "Regles de l'Acquisition" (10 noeuds, voir §5).

Hegemonie Gorn IA

  • Classe : AAGORN. Civics civic_gorn_predatory, civic_gorn_supremacy.
  • Personnalite IA : hegemonic_imperialists_gorn, ajustee pour que les depenses de colonisation restent assez elevees et permettent aux Gorn de continuer a s'etendre malgre leur penchant militariste.
  • Portraits : gfx/portraits/portraits/portraits_gorn.txt - plus d'uniformes Stellaris generiques (clothes_selector = "no_texture").
  • Systemes d'origine : Galdonterre, Cestus, Finibus.
  • Coques : Makar, Ddraig, Sarath, Balaur, Vazkoth, Hegemony Bulwark, Kethar Command (common/technology/cp26_gorn_orion_hull_tech.txt).

Regroupes par theme narratif/systemique. Le namespace (ns) est la cle technique utilisee par les fichiers de localisation correspondants.

9. Pour les futurs contributeurs

  • Ne modifiez jamais un fichier vanilla directement dans le dossier de jeu - toute modification doit passer par un fichier CP26, soit via replace_path (fichier entier remplace, declare dans descriptor.mod), soit via un fichier additionnel autonome.
  • Avant de chercher un contenu dans un fichier "racine" (00_ufop_nodes.txt, hornblower_initializers.txt, hornblower_game_start.txt), verifiez s'il n'est pas reduit a un stub - voir le motif stub+split en §1.
  • Respectez les prefixes de nommage existants (§1) pour rester coherent : cp26_* pour du contenu narratif neuf, zz_cp26_* pour des correctifs/reglages tardifs.
  • Le CHANGELOG.md est en retard - si vous le mettez a jour, verifiez d'abord l'etat reel du code (comme cette page l'a fait) plutot que de vous fier aux dernieres entrees.
  • Testez les gardes de scope (exists = owner/planet/event_target:...) - plusieurs correctifs CP26 documentes ci-dessus existent uniquement pour eviter des erreurs de contexte de scope detectees dans error.log. Ce motif est courant dans le mod et doit etre reproduit pour tout nouveau contenu.
  • Attention aux regressions de performance : certains evenements ont ete desactives en urgence en cours de developpement (hornblower_country_events.txt, §2) suite a des gels de partie. Testez les nouveaux pulses/evenements periodiques sur de longues parties avant de les livrer.
