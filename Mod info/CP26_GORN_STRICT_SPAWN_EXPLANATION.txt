CP26 GORN STRICT SPAWN - EXPLANATION
Date: 2026-05-05

Goal
- Make Gorn spawn much more deterministic in the Xindus/Tribble frontier zone.
- Keep a safe fallback if this strict zone cannot be used.

What was changed
1) Added dedicated anchor initializers with unique system flags
   - File: common/solar_system_initializers/zz_cp26_anchor_initializers.txt
   - New initializers:
     - cp26_xindus_anchor_initializer (adds star flag cp26_xindus_anchor)
     - cp26_tribble_anchor_initializer (adds star flag cp26_tribble_anchor)

2) Rewired Xindus and Tribble to use those anchor initializers
   - Files:
     - map/setup_scenarios/Alpha-Beta_medium.txt
     - map/setup_scenarios/tutorial.txt
   - Changes:
     - NAME_Xindus -> cp26_xindus_anchor_initializer
     - NAME_Tribble -> cp26_tribble_anchor_initializer

3) Tightened Gorn anchor selection logic
   - File: events/aa_gorn_start_events.txt
   - New order:
     a) Pick a NOT_USED neighboring system around cp26_xindus_anchor or cp26_tribble_anchor
     b) If none, pick a second-ring NOT_USED neighbor around those anchors
     c) If still none, fallback to UFOP/Klingon border logic

4) Added buffer distance from anchor to Gorn capital
   - File: common/scripted_effects/aa_gorn_effects.txt
   - Change:
     - spawn_gorn_system min_jumps/max_jumps: 1 -> 2
   - Result:
     - The Gorn capital is now spawned farther from the anchor, creating
       a more consistent empty-space buffer between Gorn and nearby empires.

About "systems generated in UFP"
- In current Gorn effects, expansion systems are created with NOT_USED-space checks
  before ownership is assigned:
  - setup_gorn_territory -> create_starbase owner = gorn_country
  - selection uses is_not_used_space in the start event
- Practical consequence:
  - The strict spawn does NOT overwrite an already owned UFP system.
  - It spawns next to UFP/Klingon frontier systems, then claims free neighboring systems.

Notes
- If the local frontier is fully occupied, fallback logic may be used.
- Even then, the script still prioritizes free systems (not already owned).

Update - 2026-05-07
- The Gorn generator was reset away from fixed Xindus/Tribble targeting.
- It now works like the Tholian-style logic: it builds candidate systems around the UFP/Klingon frontier and picks a valid empty pocket from that zone.
- The Gorn capital and side systems now spawn locally from that pocket with connected hyperlanes, so the result should stay in the intended frontier area instead of jumping far away.
- The old broad-distance placement was removed because it could choose a correct anchor but create the actual Gorn home system outside the requested zone.
