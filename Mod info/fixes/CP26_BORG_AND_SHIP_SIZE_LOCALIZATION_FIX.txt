CP26 Borg cube and ship size localization fix

Date: 2026-05-06

Files changed:
- events/hornblower_country_events.txt
- localisation/english/zz_cp26_ship_size_modifiers_l_english.yml
- localisation/french/zz_cp26_ship_size_modifiers_l_french.yml

What changed:
- Replaced the old Borg cube spawn design reference from NAME_BorgCube to NAME_BorgCube_large.
- Added English localization keys for missing automatically generated ship size modifiers.
- Added French localization keys for missing automatically generated ship size modifiers.

Why the Borg fix was needed:
- The event in hornblower_country_events.txt tried to create a ship with design = "NAME_BorgCube".
- The actual global ship designs available in common/global_ship_designs/hornblower_designs.txt are:
  - NAME_BorgCube_large
  - NAME_BorgCube_mid
  - NAME_BorgCube_small
- There is localization for NAME_BorgCube, but no matching ship_design with that name.
- That means the old event could create the Borg country/fleet context but fail to create the actual Borg cube ship.
- NAME_BorgCube_large was chosen because this event represents the single major Borg cube from the older Borg cube chain.

Expected in-game effect:
- The old Borg cube event chain should now spawn the intended large Borg cube instead of referencing a missing design.
- This should not alter the modern Borg Crisis wave spawns, which already use NAME_BorgCube_large, NAME_BorgCube_mid, and NAME_BorgCube_small through scripted effects.

Why the localization fix was needed:
- setup.log reported many missing keys like corvette_build_speed_mult, corvette_build_cost_mult, corvette_upkeep_mult, corvette_hull_mult, and corvette_hull_add.
- These keys are automatically generated by the engine for ship size modifiers.
- Missing localization usually does not break gameplay, but it can pollute setup.log and can show raw technical keys in tooltips.

Expected localization effect:
- Ship size modifier tooltips should display readable English/French text instead of raw keys.
- setup.log should be much cleaner after launching the game again.

Notes:
- No vanilla game files were edited.
- The fixes are applied through CP26 only.
- The localization files use dynamic references such as $corvette$ so existing ship size names are reused instead of hardcoding every display name.

Follow-up after the 15:28 relaunch:
- The French ship size modifier localization file was reported as missing UTF-8 BOM.
- Both new ship size modifier localization files were converted to UTF-8 BOM to match the rest of the mod localization files.
- debug.log still reported _random_ planet class failures in misc_system_initializers.txt lines 609-622.
- Added class = rl_unhabitable_planets to that remaining trinary planet block so the game no longer has to infer an invalid random planet class there.
