CP26 Ferengi Host Planet Reveal and Empire Card Cleanup
Date: 2026-05-21

1. Ferengi host planet visibility
- Removed the temporary Intel-heavy approach.
- Branch interactions now reveal:
  - each host colony
  - the host colony's solar system
  - every planet in that solar system
- Applied when:
  - opening branch setup on a valid host colony
  - opening a branch report on an existing host colony
  - creating a branch office

- common/button_effects/cp26_button_effects.txt

- Let Ferengi players actually see host worlds tied to commercial branch play,
