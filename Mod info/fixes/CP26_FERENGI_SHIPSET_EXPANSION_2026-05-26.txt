CP26 FERENGI SHIPSET EXPANSION
Date: 2026-05-26

Summary
- Expanded the playable Ferengi naval roster to better match the shipset already present in CP26.
- Kept the Ferengi progression tied to their commercial branch instead of introducing a Ferengi colossus.

Implemented
- Added a true Ferengi cruiser size:
  - ferengicruiser
  - visual: Nandi mesh
  - research gate: tech_cruiser_unlock

- Reframed the Ferengi heavy hull:
  - ferengibattleship now represents the Marauder Galleon / Zark line
  - research gate corrected to tech_battleship_unlock

- Added a Ferengi titan:
  - ferengititan
  - visual: Ooron mesh
  - research gate: tech_titan_unlock
  - construction still requires titan yards

- Added new section templates and default designs for:
  - cruiser
  - titan

- Added tech-facing Ferengi localisation so the shared hull tech tree now reads as:
  - D'Kora Marauder
  - Nandi Cruiser
  - Marauder Galleon
  - Ooron Command Titan

Design Intent
- Keep Ferengi early game distinct but not over-militarized.
- Let their late military escalation track the already implemented branch-office / orbital platform economy:
  - destroyer start
  - cruiser via normal hull progression
  - battleship only after Acquisition Platforms
  - titan only after Quark Orbital Licenses

Not Implemented
- No Ferengi colossus gameplay branch yet.
- No Ferengi juggernaut gameplay branch yet.
- Klingon/Romulan/Cardassian shipset expansion intentionally deferred.
