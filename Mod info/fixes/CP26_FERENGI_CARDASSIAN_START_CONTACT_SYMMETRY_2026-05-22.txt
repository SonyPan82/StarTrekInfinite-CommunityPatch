CP26 - Ferengi/Cardassian start contact symmetry
Date: 2026-05-22

Issue
- When starting as Ferengi, the player could know Cardassia.
- When starting as Cardassia, the reciprocal contact with the Ferengi was not guaranteed.

Fix
- Updated events/zz_cp26_setlik_fix.txt in cp26_setlik.4 so Ferengi/Cardassian start contact is established symmetrically:
  - Ferengi establishes hidden contact + communications with Cardassia
  - Cardassia establishes hidden contact + communications with Ferengi
- Removed the old player-only gate from this contact block so the setup works regardless of which side the player chooses.

Expected result
- Ferengi and Cardassians should both know each other at game start, from either perspective.
