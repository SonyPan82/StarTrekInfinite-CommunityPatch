CP26 Fix Notes - 2026-05-21
=================================

Scope
-----
Three fixes grouped together:

1. Ferengi commercial pact visibility
2. Ferengi ship / UI flag assets
3. Ferengi <-> Cardassian starting relations


1. Ferengi commercial pact visibility
-------------------------------------
Problem:
- Ferengi commercial pacts did not reliably make the host empire's colonies
  visible enough for branch office management.
- The previous monthly reveal approach was intentionally removed because it was
  too heavy and too broad.

Implemented fix:
- Added a one-shot reveal hook directly on commercial pact acceptance.
- File:
  common/diplomatic_actions/00_actions.txt
- Action patched:
  action_form_commercial_pact

Behavior:
- If the actor is Ferengi, the recipient's surveyed space is granted to the
  Ferengi side for:
  - the host country itself
  - all owned colonies
  - each colony's solar system
  - all planets in those colony systems
- Symmetric logic also applies if the recipient is Ferengi.

Reasoning:
- This avoids a monthly CPU sweep.
- Reveal now happens exactly when the diplomatic condition is created.


2. Ferengi ship / UI flag assets
--------------------------------
Problem:
- Ferengi still lacked working small/bottombar flag behavior while Gorn,
  Orion and Tholian were already using lowercase dedicated assets.
- Ferengi was still pointing at mixed-case vanilla asset names
  (flag_Ferengi_35.dds) through many sprite aliases.

Implemented fix:
- Copied the vanilla Ferengi emblem files into the mod using the same lowercase
  naming convention as the working custom empires:
  - flags/emblem/flag_ferengi.dds
  - flags/emblem/small/flag_ferengi.dds
  - flags/emblem/bottombar/flag_ferengi.dds
  - flags/emblem/bottombar/flag_ferengi_bottombar.dds
  - flags/emblem/map/flag_ferengi.dds

- Updated:
  interface/aa_ferengi_stuff.gfx

New wiring:
- icon / bottombar aliases -> flag_ferengi_bottombar.dds
- small aliases -> small/flag_ferengi.dds
- main emblem aliases -> emblem/flag_ferengi.dds

Reasoning:
- This aligns Ferengi with the same asset layout already proven to work for the
  other custom species.


3. Ferengi / Cardassian starting relations
------------------------------------------
Problem:
- User wanted Ferengi and Cardassians to begin in a naturally favorable state.

Implemented fix:
- Added a dedicated opinion modifier:
  common/opinion_modifiers/zz_cp26_ferengi_cardassian_opinions.txt
  cp26_ferengi_cardassian_trade_affinity = +60, unique

- Applied mutually during Ferengi start setup:
  events/aa_ferengi_start_events.txt

Behavior:
- Ferengi receive the opinion modifier toward Cardassia.
- Cardassia receives the same opinion modifier toward Ferengi.


Notes
-----
- This patch does not restore the old monthly visibility sweep.
- This patch does not alter the branch revenue backend.
- If a save was already loaded before the commercial pact existed, a fresh pact
  acceptance or a fresh game is the best validation path for the visibility fix.
