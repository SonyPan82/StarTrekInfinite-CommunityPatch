================================================================================
  CP26 - MISSION EVENTS : FIX OPTIONS FALLBACK POUR EMPIRES MINEURS
  Date : 2026-05-17
  Version cible : Star Trek Infinite v1.0.7 + CP26
================================================================================

PROBLEME
--------
Les missions suivantes declenchaient l'erreur dans error.log :
  "Triggered Event mission.XXX for AI [Empire] has no options with positive ai_chance!"

Cette erreur se produit quand un event fire pour un pays IA et qu'AUCUNE option
n'est visible pour lui. L'IA reste bloquee sur cet event indefiniment.

CAUSE
-----
Chaque mission avait 4 options, chacune gatee par un trigger exclusif :
  is_ufop = yes | is_klingon = yes | is_romulan = yes | is_cardassian = yes

Ces missions peuvent aussi fire pour des empires mineurs (Bajoran, Farian,
Kaelon, Kesprytt, etc.) qui ne sont aucun des 4 majors. Aucune option ne
les satisfait -> zero ai_chance valide -> erreur en log + IA bloquee.

IMPACT CPU
----------
Negligeable. Le trigger NOT { OR { ... } } est evalue une seule fois au moment
ou l'event fire, pas en continu. C'est 4 comparaisons booliennes par event.

FIX APPLIQUE
------------
Ajout d'une option fallback dans chacune des 5 missions concernees :

  option = {
      trigger = { NOT = { OR = { is_ufop = yes is_klingon = yes
                                 is_romulan = yes is_cardassian = yes } } }
      name = mission.XX.a   # reutilise la clef de localisation UFOP (texte generique)
  }

L'option fallback reutilise la cle de localisation de l'option UFOP car elle
est suffisamment neutre. Les empires mineurs sont toujours IA, ils n'affichent
pas le texte a l'ecran.
