CP26 Ferengi constructor order and platform tooltip pass
Date: 2026-05-22

Summary
- Ferengi orbital platforms now expose explicit megastructure description keys
  and detail text so the panel shows their yield and host effects instead of raw
  localisation keys.
- Ferengi player construction now uses a more physical flow:
  - the selected Ferengi construction ship is remembered when opening the
    platform builder
  - choosing a platform marks the host colony with a temporary construction
    modifier and pending flag
  - a situation-log event chain opens to indicate that a commercial platform is
    being established
  - the saved construction ship receives an auto-move order toward the selected
    colony
  - on arrival, the orbital platform is spawned and the host modifier is
    applied

Notes
- The player Ferengi flow now allows only one platform construction order at a
  time. This keeps the constructor/journal/movement logic deterministic and
  prevents overlapping pending builds while the V2 platform system is still
  evolving.
- AI Ferengi placement is unchanged by this pass and still uses the scripted
  backend.
