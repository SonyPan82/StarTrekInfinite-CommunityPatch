CP26 - Borg Crisis Safe Chain Patch
================================================================================
Date    : 2026-05-27
Statut  : Implémenté
Scope   : Situation log, chaîne Janeway/Voyager, chaîne The Freed, cleanup
Timing  : Inchangé - @late_to_end_crisis_time reste à 29160 jours (~81 ans)
================================================================================

1. OBJECTIF
--------------------------------------------------------------------------------
Ce patch corrige les couches de suivi et de finition de la crise Borg sans
changer son rythme global ni son équilibrage militaire.

Le but est que :

  - le chemin Janeway/Voyager soit visible proprement dans le situation log ;
  - les trois projets Voyager CP26 soient rattachés à la bonne chaîne ;
  - la phase "The Freed" existe réellement comme chaîne finale ;
  - les chaînes Borg se ferment proprement en victoire ou en défaite ;
  - les clés de localisation ajoutées ne s'affichent pas en brut ;
  - le délai vanilla de 81 ans après échec/refus de Janeway reste intact.

3. PATCH SÛR - JANEWAY / VOYAGER
--------------------------------------------------------------------------------

Avant :

  - La chaîne vanilla `borg_crisis_end` existait, mais n'était pas démarrée
    par les events Janeway.
  - Les projets CP26 `PROBE_DEFENSES`, `COUNTERACT_MEASURES` et `DELIVERANCE`
    avaient `#event_chain = "borg_crisis_end"` commenté.
  - Le joueur pouvait faire les projets, mais la progression n'était pas
    affichée proprement dans le situation log.

Après :

  - `borg_crisis.380` démarre `borg_crisis_end`.
  - Les trois projets CP26 Voyager sont rattachés à `borg_crisis_end`.
  - Un compteur `janeway_gambit_steps` suit les trois étapes :

      1. PROBE_DEFENSES réussi       -> borg_crisis.383
      2. COUNTERACT_MEASURES réussi  -> borg_crisis.384
      3. DELIVERANCE réussi          -> borg_crisis.391

  - Sur succès de `DELIVERANCE`, la chaîne progresse à 3/3 puis la victoire
    Janeway arrive via le flow vanilla :

      DELIVERANCE
        -> borg_crisis.391
        -> borg_crisis.445 après @janeway_success_to_victory_time
        -> set_borg_crisis_won
        -> borg_crisis.450

4. PATCH SÛR-MOYEN - THE FREED
--------------------------------------------------------------------------------

Avant :

  - Le bloc `borg_crisis_end_the_freed` était commenté en vanilla.
  - Les events `borg_crisis.430` et `borg_crisis.440` existaient, mais sans
    chaîne de situation log dédiée.
  - Décommenter le bloc seul n'aurait pas suffi : il n'y avait ni begin,
    ni compteur, ni fin de chaîne.

Après :

  - `borg_crisis_end_the_freed` est défini dans l'override event_chains.
  - La chaîne a un compteur `freed_support_received` avec max = 1.
  - `borg_crisis.430` démarre la chaîne si elle n'existe pas déjà.
  - L'option "Enemy of My Enemy" ajoute 1 au compteur puis lance `borg_crisis.440`.
  - L'option "Fight Own Battle" donne les récompenses vanilla puis ferme la
    chaîne `borg_crisis_end_the_freed`.

Important :

  The Freed reste un soutien narratif/militaire. Ce n'est pas une condition de
  victoire directe. La victoire finale du chemin highways vient toujours de la
  destruction du dernier cube Imperatoris via `borg_crisis.510`.

5. CLEANUP VICTOIRE / DÉFAITE
--------------------------------------------------------------------------------

Les chaînes suivantes sont maintenant fermées proprement pour tous les empires
majeurs en cas de victoire ou de défaite :

  - borg_crisis_end
  - borg_crisis_end_highways
  - borg_crisis_end_the_freed

Cas couverts :

  - Victoire Janeway :
      borg_crisis.445

  - Victoire failsafe si aucun cube Imperatoris n'existe au moment de l'invasion :
      borg_crisis.401

  - Victoire par destruction du dernier cube Imperatoris :
      borg_crisis.510

  - Défaite :
      borg_crisis.460

6. GARDE-FOU ÉCHEC JANEWAY
--------------------------------------------------------------------------------

Ajout du flag pays :

  cp26_borg_janeway_failure_processed

Pourquoi :

  En vanilla, si Janeway meurt pendant un projet, l'event de mort peut appeler
  `borg_crisis.390`, puis l'abort du projet peut aussi déclencher un échec.
  Le flag empêche que l'échec Janeway soit traité plusieurs fois et que
  `borg_crisis.400` soit planifié plusieurs fois.

Le flow d'échec reste vanilla côté timing :

  borg_crisis.390
    -> borg_crisis.400 après @late_to_end_crisis_time

Avec :

  @late_to_end_crisis_time = 29160

8. CE QUI N'A PAS ÉTÉ CHANGÉ
--------------------------------------------------------------------------------

Ce patch ne modifie pas :

  - les timers de crise Borg ;
  - les 81 ans après échec/refus Janeway ;
  - la force des cubes Borg ;
  - les vagues Borg ;
  - les war goals ;
  - les conditions de victoire vanilla.

La victoire reste :

  A) Chemin Janeway :
       réussir PROBE_DEFENSES -> COUNTERACT_MEASURES -> DELIVERANCE.

  B) Chemin highways / guerre finale :
       détruire tous les cubes Imperatoris.

  C) Failsafe :
       si aucun cube Imperatoris n'existe au moment où l'invasion doit démarrer,
       la crise est marquée gagnée.

10. TEST CONSOLE RECOMMANDÉ
--------------------------------------------------------------------------------

Pour valider visuellement en jeu :

  1. Déclencher / avancer jusqu'à `borg_crisis.380`.
     Vérifier que `borg_crisis_end` apparaît dans le situation log.

  2. Réussir les trois projets Voyager.
     Vérifier que le compteur Janeway progresse et que la victoire arrive via
     `borg_crisis.445` puis `borg_crisis.450`.

  3. Forcer un échec Janeway.
     Vérifier que `borg_crisis.390` ne planifie pas plusieurs fois la suite.
     Vérifier que le délai reste 29160 jours.

  4. Déclencher `borg_crisis.430`.
     Vérifier que `borg_crisis_end_the_freed` apparaît avec titre/description
     localisés et que le compteur progresse après l'option de soutien.

  5. Détruire le dernier cube Imperatoris.
     Vérifier que `borg_crisis.510` ferme les chaînes et lance la victoire.
