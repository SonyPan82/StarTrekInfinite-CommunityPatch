CP26 — GUIDE : AJOUTER UN EMPIRE CONTENDER
===========================================
Exemple de référence : Alliance Ferengi (2026-05-17)
Basé sur le pattern Orion/Tholian/Gorn.

RÈGLE ABSOLUE : ne jamais modifier les fichiers hors du dossier CP26/.
Les fichiers du jeu de base et d'Infinite sont en lecture seule.

PIÈGE CRITIQUE — late_init_effect non fiable
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Dans cette version du moteur (Garrett 1.0.7), le late_init_effect de
l'initializer système n'est PAS toujours appelé pour les empires contenders
spawné via setup_scenarios. Cela se manifeste comme suit :
- L'init_effect s'exécute entièrement (pays créé, espèce créée) ✓
- Le late_init_effect (set_owner, create_starbase) ne tourne jamais ✗
- Résultat : pays créé dans les logs, planète vide, empire invisible

SOLUTION OBLIGATOIRE : créer un événement on_game_start (pattern Orion).
L'événement on_game_start est déclenché APRÈS toute l'initialisation et
est garanti d'exécuter. C'est là que se fait le vrai setup de la capitale.

NE PAS mettre dans l'initializer :
- create_ship_design / add_ship_design → peut avorter le late_init_effect
  (source : debug Ferengi 2026-05-17, FRG2 apparaît mais FRG3 absent)
