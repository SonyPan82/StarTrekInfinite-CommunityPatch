CP26 — MINOR SPECIES TRAITS (60 traits species) — 2026-05-12
================================================================================

CONTEXTE
--------------------------------------------------------------------------------
Les 20 prescripted minor factions de CP26 (19 sous classe HRB_DIPLO/TRADE/HARDY
+ Jnaii sous classe JNA) référencent CHACUNE 3 traits species dans leur fichier
`prescripted_countries/00_*.txt`. Exemples :

    species = {
        class = "HRB_DIPLO"
        portrait = "bajoran"
        trait = "trait_survivors_bajoran"
        trait = "trait_prophetic_believer_bajoran"
        trait = "trait_selective_researchers_bajoran"
    }

PROBLÈME : ces 60 traits n'étaient définis NULLE PART. Aucun fichier dans
`common/traits/`, aucune localisation. Le moteur les ignorait silencieusement,
et les pops de ces espèces n'avaient AUCUN trait species effectif — juste les
défauts du moteur. C'était un trou massif de gameplay et de lore qui touchait
toutes les rencontres avec les minor factions.

À titre de comparaison, les 4 empires CP26 *majeurs* (Tholian, Denobulan, Remus,
Risan) ont leurs traits species correctement définis dans des fichiers dédiés
(`aa_tholian_traits.txt`, `denobulan_traits.txt`, etc.). Les minors n'avaient
jamais eu droit au même traitement.


DÉCISION : STRATÉGIE B — CRÉATION COMPLÈTE
--------------------------------------------------------------------------------
Trois stratégies étaient possibles :

  A) Hybride : 1 trait signature unique par race + 2 archetypes partagés par
     classe HRB_* (28 traits). Léger mais Bajoran = Trill en 2/3 des stats.

  B) Création complète : 60 traits 100% uniques, fidélité lore maximale,
     parité avec le traitement des 4 majeures. (RETENU)

  C) Pack minimal : 9 traits archetype seulement, refactor des 19 prescripted.
     Trop génériquE — perte totale d'identité par race.

Le choix B s'imposait pour quatre raisons :

  1. PARITÉ MAJEURES / MINEURES — les 4 majeures ont chacune 3 traits species
     uniques. Faire un système hybride pour les minors créerait une asymétrie
     "les majeures ont du contenu unique, les mineures partagent" peu Star Trek.

  2. NOMS DÉJÀ POSÉS — les 60 noms dans les prescripted (trait_smugglers_boslic,
     trait_neuro_engineers_ktarian, trait_matriarcal_houses_betazoid, etc.) sont
     manifestement issus d'un travail de design original (lore Star Trek).
     Les jeter au profit d'archetypes génériques aurait gâché ce capital.

  3. AUCUN PRESCRIPTED À TOUCHER — la création des 60 traits sous leurs noms
     existants évite toute modification des 19 fichiers prescripted_countries
     (zéro risque de casser leurs spawns / civics / governments).

  4. MÉMORABILITÉ — quand le joueur rencontre les Cairn et lit
     "Pure Telepaths : +1 envoy, +0.10 society research", c'est lore-cohérent
     et mémorable. Avec un trait générique HRB_* ça aurait grincé.

PHILOSOPHIE DE DESIGN
--------------------------------------------------------------------------------
Budget par race : ~+3 à +5 cost cumulé (positif net "above vanilla", fitting
le statut bespoke/prescripted des minors — ils ne sont pas inférieurs aux
races standards). Pattern récurrent :

    trait #1  cost = 4   trait signature majeur (effet lore phare)
    trait #2  cost = 2   trait positif secondaire
    trait #3  cost = -1  trait drawback culturel (équilibre)

Variantes mineures (certaines races avec 3 traits cost=2, certaines avec 2
traits forts et 1 nul). Les valeurs des modifiers sont délibérément MODESTES
(±10-20%) pour éviter de transformer ces races en cheat-codes ou en boulets.

Modifiers utilisés — TOUS observés dans des trait files vanilla/CP26
existants (aa_tholian_traits, denobulan_traits, risan_traits, remus_traits,
00_hornblower_leader_traits) :

    pop_growth_speed                              pop_amenities_usage_mult
    pop_housing_usage_mult                        planet_stability_add
    planet_pops_organics_food_upkeep_mult         planet_pops_energy_upkeep_mult
    planet_jobs_worker_produces_mult              planet_jobs_specialist_produces_mult
    planet_jobs_ruler_produces_mult               planet_jobs_unity_produces_mult
    planet_jobs_research_produces_mult            army_health
    army_damage_mult                              leader_age
    trade_value_add                               envoys_add
    diplo_weight_economy_mult                     ship_speed_mult

HOTFIX 2026-05-12 (crash SIGSEGV au load) — Les modifiers research par catégorie
`planet_jobs_society_research_produces_mult`, `..._physics_..._mult` et
`..._engineering_..._mult` (12 occurrences sur 9 races) étaient présents dans le
fichier vanilla STI mais **commentés** dans tous les usages et **rejetés à
l'execution** (`modifier.cpp:2758: Invalid modifier`). Effet observé : crash
SIGSEGV dans `CullAndUpdateEntitiesRecursive` au premier tick après le load.
Remplacés par `planet_jobs_research_produces_mult` (modifier générique research,
réellement supporté par STI, utilisé dans `trait_intelligent` et nombreux autres
traits species vanilla). Conséquence design : le bonus/malus s'applique à la
catégorie research globale plutôt qu'à une sous-catégorie ; pas de perte de
lore puisque seule la magnitude est conservée.

Structure standard de chaque trait :

    trait_X_race = {
        cost = N
        potential_crossbreeding_chance = 1.0
        opposites = { "trait_nonadaptive" "trait_adaptive" "trait_adaptive_lithoid" }
        allowed_archetypes = { BIOLOGICAL }
        modifier = { ... }
    }

SOMMAIRE — IDENTITÉ RECOGNAISSABLE PAR ARCHETYPE
--------------------------------------------------------------------------------
Avec ces 60 traits, chaque archetype a une "couleur" reconnaissable dans le
gameplay, tout en gardant des différences race-vs-race.

  HRB_DIPLO  → Tendance globale : recherche société + leader long-lived
               + un trait drawback récurrent type "amenity heavy" ou "slow"
               + signatures uniques : Bajoran combat/survie, Betazoid envoys,
                 Trill leader âge, Iyaaran ascèse, Kaelon résilience,
                 Malcorian stabilité.

  HRB_TRADE  → Tendance globale : trade_value + production specialist/worker
               + un trait drawback "social" (instabilité, food, stabilité)
               + signatures uniques : Bolian aristo, Boslic ship speed,
                 Hupyrian armée robuste, Lissepian envoys, Pelian admin.

  HRB_HARDY  → Tendance globale : armée + stabilité + research society
               + un trait drawback "instabilité interne" ou "pacifisme"
               + signatures uniques : Cairn télépathie (envoys), Ktarian
                 engineering, Talarian discipline, Acamarian guerriers,
                 Idanian intel, Kesprytt utilitarisme, Tanugan loi.

  JNA        → Société conformiste très stable, recherche société élevée,
               aucun drawback (3 traits positifs équilibrés).

IMPACT GAMEPLAY ATTENDU
--------------------------------------------------------------------------------
  - Chaque rencontre avec une minor faction est désormais lisible : leurs
    forces et faiblesses ont une saveur lore-cohérente.
  - L'AI minor faction joue mieux ses cartes : un Bolian focusé trade, un
    Acamarian focusé army, un Trill focusé long-term leaders.
  - Les pops de ces races, si elles intègrent l'empire du joueur (migration,
    conquête, vassalité), apportent leurs traits — donc un Talarien vassal
    devient une excellente garnison, un Lissepian intégré devient un
    booster de commerce, etc.
  - Plus aucun warning "trait not found" pour ces 60 noms.
