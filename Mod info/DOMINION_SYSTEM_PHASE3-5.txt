PHASE 3 — INFILTRATION CHANGELING  (DTL 40-60)
================================================================

DÉCLENCHEUR
-----------
DTL atteint 40 (flag cp26_dtl_40_reached) + Phase 2 résolue
→ Yearly tick fire event .500 pour le découvreur du wormhole


MÉCANIQUE PRINCIPALE
--------------------
Les Fondateurs infiltrent l'Alpha Quadrant.
Stocké comme variable "cp26_changeling_infiltration" sur le pays Dominion (0-10).

Effets possibles selon niveau d'infiltration :
  - Sabotage d'une station (malus économique sur planète aléatoire)
  - Faux ordres militaires (flotte du joueur déplacée — difficile à implementer, simuler via event)
  - Désactivation de boucliers (malus défense planète)
  - Assassinat politique (leader aléatoire retiré)
  - Traités sabotés (malus opinion vers un allié)

Génère un événement "incident suspect" aléatoire chaque 2-3 ans tant que
l'infiltration n'est pas réduite.


EVENT .500 — INTRODUCTION PHASE 3 (flavor)
-------------------------------------------
"Des anomalies dans les rapports de commandement. Un officier supérieur
s'est comporté de façon incohérente. Les services de renseignement
soupçonnent une présence étrangère dans nos structures de pouvoir."

  → ok → fire .510 après 60 jours


EVENT .510 — PARANOÏA (choix principal + ship requis)
------------------------------------------------------
"Le niveau d'infiltration Changeling dans nos systèmes est inconnu.
Trois options sont sur la table."

CHOIX A — Tests sanguins obligatoires (aucun ship requis, effet immédiat)
  - Réduit infiltration (changeling_infiltration -3)
  - Malus moral/unité (-unity mensuelle)
  - Malus stabilité planètes
  - DTL -3 (les Changelings sont découverts, reculent temporairement)
  → fire .511 après 30 jours (résultat des tests)

CHOIX B — Préserver les libertés civiles (aucun ship requis)
  - Infiltration augmente (+3)
  - Malus science (sabotages discrets)
  - DTL +5 (Dominion profite de l'ouverture)

CHOIX C — Utiliser Section 31 (vaisseau espion requis / ou influence cost)
  Mécanique : coût influence élevé (300-500) + flag cp26_section31_active
  - Débloque opérations secrètes contre le Dominion
  - Sabotage Dominion : DTL -8
  - Infiltration -5 (Section 31 neutralise les Changelings)
  - Risque diplomatique : opinion -20 avec Bajor et Fédération
  → fire .512 après 45 jours


EVENT .511 — RÉSULTAT DES TESTS SANGUINS
-----------------------------------------
"Les tests ont révélé [N] imposteurs dans nos rangs."

CHOIX A — Emprisonner et interroger
  - Intelligence bonus (physique/société)
  - DTL -2 supplémentaire

CHOIX B — Exécuter discrètement
  - Infiltration -2 supplémentaire
  - Risque : si un innocet était parmi eux → moral -


EVENT .512 — RAPPORT SECTION 31
---------------------------------
"Nos agents ont infiltré les réseaux Changeling. Les résultats sont..."

CHOIX A — Succès complet
  - DTL -10, infiltration -5
  - Bonus influence

CHOIX B — Succès partiel avec fuite
  - DTL -5, infiltration -2
  - Dominion désormais au courant → DTL +3 retour


EVENT .520 — INCIDENT CHANGELING (se répète tant qu'infiltration > 3)
-----------------------------------------------------------------------
Fires aléatoirement (yearly, 20% chance) si cp26_changeling_infiltration > 3

Exemple de random_list d'effets :
  25% : "Un conseiller militaire était un Changeling — ordres falsifiés"
         → malus unité -100, une flotte déplacée (simulé)
  25% : "Sabotage d'une station orbitale"
         → malus économique planète aléatoire (-energy -50)
  25% : "Traité diplomatique compromis"
         → opinion -15 avec pays allié aléatoire
  25% : "Tentative d'assassinat sur un leader"
         → kill_leader aléatoire (si possible) ou retire leader temporairement

SHIP REQUIS pour répondre : ship_event ou special project "CP26_CHANGELING_HUNT"
  - Vaisseau espion / science ship à une planète marquée
  - Durée 90 jours → réduit infiltration -1 à -3 selon résultat

PHASE 4 — ALLIANCE CARDASSIA / DOMINION  (DTL 60-80)
================================================================

DÉCLENCHEUR
-----------
DTL atteint 60 (flag cp26_dtl_60_reached) + Phase 3 résolue


CONDITION D'ALLIANCE
--------------------
La probabilité que Cardassia rejoigne le Dominion est plus élevée si :
  - cp26_phase2_accused_cardassia est actif (on les a faussement accusés)
  - Opinion de Cardassia envers le joueur < -50
  - Cardassia est en guerre contre le joueur

La probabilité est réduite si :
  - Diplomatie positive avec Cardassia (opinion > 20)
  - Cardassia a un allié fort


EVENT .600 — AVERTISSEMENT (flavor)
-------------------------------------
"Des délégués Cardassiens ont été vus en réunion secrète avec des
représentants inconnus proches de la frontière Bajoran."

CHOIX A — Envoyer un vaisseau espion (special project à un système frontalier)
  - Ship requis : science ship (espionnage)
  - Durée 60 jours → révèle si alliance en cours
  → Si oui : fire .610, DTL +3
  → Si non : false alarm, petite récompense renseignement

CHOIX B — Approcher Cardassia diplomatiquement
  - Coût influence 200
  - Opinion Cardassia +30
  - Réduit probabilité alliance
  - DTL -2


EVENT .610 — CARDASSIA REJOINT LE DOMINION
-------------------------------------------
"Le préfet de Cardassia Prime a annoncé un traité de protection mutuelle
avec le Dominion. Les forces Jem'Hadar sont maintenant stationnées dans
l'espace Cardassien."

Effets :
  - DTL +15 immédiat
  - Cardassia devient subject/allié Dominion (si mécaniquement possible)
    sinon : flag cp26_cardassia_dominion_ally + opinion -50 avec Cardassia
  - Spawn d'une flotte Dominion dans l'espace Cardassien (simulation)
  - Fire événements de crise pour tous les empires (if possible)

CHOIX A — Préparer la guerre
  - Bonus militaire (unity +, naval cap +)
  - DTL inchangé

CHOIX B — Proposer une médiation d'urgence
  - Coût influence 400
  - Chance 30% de retarder l'alliance de 5 ans


EVENT .620 — CRISE POLITIQUE INTERNE  (déclenché par l'alliance)
-----------------------------------------------------------------
Fires pour empires qui ont des traités avec Cardassia.
"L'alliance Cardassienne avec le Dominion force nos gouvernements à choisir."

CHOIX A — Rompre les traités avec Cardassia
  - DTL -3 (signal de résistance)
  - Perte de resources commerciales

CHOIX B — Maintenir des relations neutres
  - DTL +5
  - Cardassia utilise la neutralité pour passer des ressources au Dominion

PHASE 5 — GUERRE DU DOMINION  (DTL 80-100)
================================================================

DÉCLENCHEUR
-----------
DTL atteint 80 (flag cp26_dtl_80_reached) + Phase 4 résolue


SYSTÈME D'INVASION PROGRESSIVE
--------------------------------

DTL 80-89 : Escarmouches et raids
  EVENT .700 — "Flotte Dominion détectée à la frontière"
  Spawn : cp26_spawn_jem_hadar_patrol (0.03 naval cap)
  Fires every 2-3 years

DTL 90-99 : Attaques de systèmes
  EVENT .710 — "Attaque en force sur [système]"
  Spawn : create_fleet_from_naval_cap = 0.07 sur un système frontalier
  Choice : défendre (unité +, DTL -2) ou évacuer (DTL +5)

DTL 100 : Invasion totale
  EVENT .720 — GUERRE TOTALE (voir ci-dessous)


EVENT .720 — ATTAQUE DE DS9 (DTL 100, once)
--------------------------------------------
"Une armada Dominion approche du système Bajoran.
Deep Space 9 est directement menacée."

CHOIX A — Défendre la station (ship requis : flotte militaire dans le système Bajoran)
  Special project CP26_DS9_DEFENSE
  - Vaisseau militaire requis (représente la flotte de défense)
  - Durée 30 jours (bataille simulée)
  - on_success (50%) : DS9 tient → big unity bonus, DTL -10
  - on_fail / random 50% : DS9 subit des dommages → malus économique

CHOIX B — Évacuer DS9
  - DS9 "capturée" (global flag cp26_ds9_captured)
  - Flotte préservée
  - Grosse perte unité et influence
  - DTL +8

CHOIX C — Miner le wormhole (décision irréversible)
  - Coupe les renforts Dominion → DTL figé, ne monte plus
  - Déclenche offensive immédiate massive (spawn grande flotte)
  - Bajor très mécontent


EVENT .730 — INTERVENTION DES PROPHÈTES (condition : DTL = 100 + wormhole non miné)
-------------------------------------------------------------------------------------
Fires aléatoirement (20% chance/year) si cp26_phase6_prophets_possible est actif
(flag posé si Bajor a une bonne opinion ou si joueur a "fait confiance aux Prophètes"
dans des événements antérieurs)

"Une vision. La Sphère de l'Orbe pulse dans la station. L'Émissaire ressent
la présence des Prophètes dans le wormhole."

CHOIX A — Faire confiance aux Prophètes
  - Flotte Dominion détruite (kill_fleet ou remove_fleet sur la flotte spawn la plus récente)
  - DTL -20
  - Bajor: grande récompense d'opinion
  - Event .731 : "La flotte du Dominion a disparu dans le wormhole..."

CHOIX B — Refuser l'aide religieuse
  - Gameplay purement militaire
  - DTL inchangé
  - Bajor mécontent

FINS POSSIBLES
================================================================

FIN 1 — VICTOIRE ALLIANCE
--------------------------
Condition : DTL redescend sous 20 (via choices cumulées) + DS9 survit
Event unique .800

"Le Dominion s'est retiré derrière le wormhole. Les Fondateurs ont jugé que
le coût d'une invasion totale de l'Alpha Quadrant était trop élevé."

Effets :
  - Grosse récompense unité + influence
  - Global flag cp26_dominion_war_victory
  - Bajor rejoint la Fédération si Fédération est le joueur (si possible)
  - Trêve : wormhole "scellé diplomatiquement" pour 20 ans (flag timed)


FIN 2 — VICTOIRE DOMINION
--------------------------
Condition : DTL reste à 100 pendant 10 ans + DS9 capturée
Event unique .810

"L'Alpha Quadrant est sous occupation partielle Dominion. Les Fondateurs
ont installé des gouverneurs dans les systèmes clés."

Effets :
  - Spawn massif de flottes Dominion (full invasion mode)
  - Malus économique et militaire sévères pour tous les empires
  - Peut déclencher une mécanique de "résistance" (events rebelles)


FIN 3 — FIN CANON DS9 (conditions multiples requises)
------------------------------------------------------
Conditions :
  - cp26_cardassia_dominion_ally actif
  - DTL entre 60 et 90
  - Bajor a une bonne relation avec le joueur

Event unique .820

"Des informations en provenance de Cardassia Prime : une révolte interne.
Les Cardassiens se battent contre leurs occupants Dominion."

CHOIX A — Soutenir la révolte Cardassienne
  - Spawn "résistance cardassienne" (flotte amie apparaît)
  - DTL -15

CHOIX B — Négocier via Odo
  (si le joueur a interagi positivement avec Bajor/Changelings)
  - Odo négocie la reddition des Fondateurs
  - DTL = 0
  - Armistice final : Dominion se retire

Fin : "Le Grand Lien a accepté les conditions. La Guerre du Dominion est terminée."

CRISES ALTERNATIVES (chaque partie différente)
================================================================

À implémenter en parallèle du système Dominion.
Une crise alternative remplace ou coexiste avec le Dominion selon un tirage
en début de partie (global flag cp26_crisis_type = X).

BORG INVASION
  - Cubes Borg spawned en bord de carte
  - Événements d'assimilation
  - Nécessite alliances pour repousser
  - Phase unique sans DTL (binary : invasion en cours ou non)

MIRROR UNIVERSE
  - Déjà partiellement dans STH (STH_MirrorUniverse)
  - Extension avec events CP26 spécifiques

TEMPORAL COLD WAR
  - Anomalies temporelles aléatoires
  - Factions "Suliban" équivalent
  - Missions de correction timeline (special projects)

SPECIES 8472
  - Entités du fluidespace
  - Très aggressives, resistantes
  - Nécessite technologie Borg pour vaincre

RÉVOLTE SYNTHÉTIQUE
  - Event interne : robots/IA se retournent
  - Malus production interne
  - Choix : réprimer ou négocier

RETOUR DES ICONIENS
  - Ancêtres technologiquement très avancés
  - Portes Iconniennes ouvrent des passages aléatoires
  - Flottes quasi invincibles → diplomatie ou retraite
