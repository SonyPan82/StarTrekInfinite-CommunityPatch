CP26 Release Note - Occupied State diplomacy and Ferengi Beta label

This pass removes the gameplay split between CP26 "vassalization" diplomacy and the existing
occupied-state system by making the proposal / subjugation pipeline resolve into occupied states.

Key player-facing effects:
- start popup now refers to diplomatic occupied states
- occupied-state overlords now receive fixed tribute through real production modifiers
- Ferengi menu empire label now shows:
  - Alliance Ferengi (Bêta)
  - Ferengi Alliance (Bêta)

Current known limitation:
- AI Ferengi does not yet autonomously place custom CP26 branch offices
