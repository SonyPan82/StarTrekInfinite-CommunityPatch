CP26 RELEASE NOTE - MEGASTRUCTURE STANDARDIZATION
Date: 2026-05-22

Highlights
- Megastructure gameplay is now standardized across CP26.
- All active civilizations begin with the base megastructure technology layer enabled.
- Non-Ferengi empires continue to use the workshop megastructure progression.
- Ferengi retain a reserved commercial megastructure line with their own unlock path.
- The Federation Fleet Museum is now a true unique megastructure instead of a loosely-scripted special case.

Ferengi rules
- Ferengi platforms require a valid commercial pact with the host empire.
- Only one Ferengi platform may exist in a host system.
- A host empire may support up to three Ferengi platforms total.
- Ferengi buildables are no longer tied only to colonized host worlds.

Federation rules
- Fleet Museum is Federation-only.
- Only one Fleet Museum may exist.

Validation still recommended
- New game:
  - verify the workshop megastructure flow for non-Ferengi empires
  - verify Ferengi tech progression and host-side placement rules
  - verify Fleet Museum uniqueness on Federation playthroughs
