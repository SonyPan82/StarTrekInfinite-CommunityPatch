[h1]Community Patch 2026 - Version 1.7.9[/h1]

[h2]Federation Tech Tree - Critical Fix[/h2]

[list]
[*] Fixed a chain-blocking bug that made the Galaxy-class and most Federation hulls permanently inaccessible. The New Orleans and Akira prerequisites now correctly require the Excelsior-class (cruiser) instead of a destroyer tech that the Federation was never able to research. This unlocks the full Federation hull chain: Excelsior → Ambassador + New Orleans → Nebula → Galaxy → Luna.
[/list]

[h2]Quest Tree — Federation[/h2]

[list]
[*] The Odyssey schematic node no longer requires the A500 rebellion arc to be fully resolved. It now unlocks as soon as the Enterprise has been upgraded and three colonies have an active A500 workforce — the condition that was always described but previously gated behind a hidden arc flag.
[*] The A500 colony counter in the Utopia Planitia node now displays a live count (e.g. 2/3) so progress is visible at a glance.
[*] The Dr. Crusher unlock condition now also displays a live count of medical clinics (e.g. 7/12).
[/list]

[h2]Diplomacy[/h2]

[list]
[*] Fixed a bug where commercial pacts and research agreements could not be proposed to minor empires despite excellent relations. The AI acceptance calculation now correctly accounts for opinion level when dealing with contender-type empires.
[*] The "Occupied State" diplomatic option is now disabled by default in the game start popup. Can still be enabled manually.
[*] Renamed the option to "Occupied State" in the game start popup for clarity.
[/list]


[h2]Ferengi[/h2]

[list]
[*] Rule 1 of Acquisition now grants a permanent modifier: commercial pacts cost no influence upkeep.
[*] All Rules of Acquisition in the quest tree now display their unlock conditions as a proper list with success/failure indicators, consistent with other faction quest trees.
[/list]

[h2]Missions[/h2]

[list]
[*] New minor empire request added: Diplomatic Colony Visit. A dignitary from a minor empire may request an escort to one of your colonies for a diplomatic visit. Accepts, rewards and penalties follow the same rules as all other minor empire missions.
[*] The escort mission now has a chance to target either a Highway Node or one of your colonies, adding variety to the request pool.
[/list]

[h2]Quest Tree — Dr. Crusher[/h2]

[list]
[*] The Dr. Crusher unlock condition has been changed. Instead of requiring the Enterprise to survey hazard systems, it now unlocks when the Federation has 12 medical clinics across its colonies — a more accessible and thematically appropriate condition.
[/list]

[h2]AI[/h2]

[list]
[*] AI empires will now more reliably build Military Bases and Fortresses when approaching their command limit. Both buildings now signal additional value to the AI when fleet capacity is above 60%, improving late-game fleet scaling.
[/list]

[h2]Bug Fixes[/h2]

[list]
[*] Fixed missing localisation for the Caravaneer fleet destroyed notification (cara.1003). The popup title, description and response options now display correctly in English and French.
[*] Fixed the generic "UNFORTUNATE" and "EXCELLENT" response keys missing from Infinite — these appeared as raw text in several base game events.
[/list]

As always, your feedback is extremely valuable for improving the project.
