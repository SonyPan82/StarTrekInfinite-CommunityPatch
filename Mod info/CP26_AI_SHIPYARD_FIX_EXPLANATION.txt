CP26 AI SHIPYARD FIX - EXPLANATION
Date: 2026-05-05

Context
- In gameplay, player empires start with a functional capital shipyard, but AI empires can start without one.
- This creates an asymmetry at game start and can slow or block early AI ship production.
- In this mod setup, major-capital initializers do not explicitly guarantee a capital starport + shipyard.

What was changed
1) Hooked a new event into game-start country on_action:
   - File: common/on_actions/zz_cp26_on_game_start.txt
   - Added: cp26_ai_shipyard.1

2) Added a new startup fix event:
   - File: events/zz_cp26_ai_shipyard_fix.txt
   - Event: cp26_ai_shipyard.1
   - Trigger:
     - is_ai = yes
     - major OR minor OR country_type = contender
     - exists = capital_scope
   - Effect (capital system only):
     - If a starbase exists and is outpost -> upgrade to starbase_starport
     - If no shipyard module -> force slot 1 to shipyard
     - If no starbase exists -> create starbase_starport, then set slot 1 to shipyard

Why this approach
- It is minimal and targeted: AI empires only (major + minor/contender), only at start, only on capital system.
- It avoids touching all individual solar system initializer files.
- It is robust to different start states (outpost, starport, or no starbase object).
