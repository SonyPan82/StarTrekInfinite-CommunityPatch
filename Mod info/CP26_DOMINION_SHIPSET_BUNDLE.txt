CP26 — Bundle shipset Dominion (dominion_01), autonome
======================================================
But : jouer avec CP26 sans dépendre d’un autre mod pour les vaisseaux Jem’Hadar /
stations du Dominion.

Contenu
-------
1. gfx/models/ships/dominion_01/ — meshes, .gfx, .asset, textures, anims (vaisseaux + orbital station).
2. gfx/models/ships/starbases/recycle/dominion/ — mesh / textures station de recyclage.
3. gfx/models/ships/dominion_01/zz_cp26_dominion_01_starbase_entities.asset — entités starbase (outpost → citadel, construction, tourelles).
4. gfx/models/ships/dominion_01/zz_cp26_dominion_01_military_defense.asset — section plateforme défense militaire.
5. gfx/models/ships/dominion_01/zz_cp26_dominion_01_recycle_entities.asset — débris + stations recycle v1/v2.
6. common/graphical_culture/zzz_cp26_dominion_01_graphical_culture.txt — enregistre dominion_01 (fallback generic_01).

Référence d’origine (copie initiale) : assets style Star Trek mod Stellaris ; chemins
gardés identiques (dominion_01_*, dominion_recycle_*) pour compatibilité avec les
ship_sizes / starbases du jeu.

Non inclus (rare / cosmétique) : icônes ship designer STH (interface/icons/ship_parts/data),
empire_select_dummy, autres cultures qui réutilisaient un mesh Dominion.
