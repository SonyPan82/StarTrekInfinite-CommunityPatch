CP26 - Rura Penthe Global Start Guarantee
Date: 2026-05-21

Problem
- Rura Penthe was still missing when starting as the Federation.
- The previous fix reduced conflicts inside the Beta Penthe initializer, but the actual colony creation still depended on Klingon-only startup timing.

Fix
- Added a new hidden startup repair scheduler:
  - events/zz_cp26_spawn_repair_events.txt -> cp26_spawn_repair.2
- Added a delayed execution event:
  - events/zz_cp26_spawn_repair_events.txt -> cp26_spawn_repair.3
- Added it to:
  - common/on_actions/zz_cp26_on_game_start.txt

How it works
- `cp26_spawn_repair.2` now only schedules a delayed repair 5 days after game start.
- `cp26_spawn_repair.3` runs after the galaxy and major countries are fully initialized.
- It captures the real Klingon country via `has_country_flag = klingon`.
- It then finds the planet with `planet_rura_penthe`.
- If Rura Penthe is still not a colony, it creates the colony.
- If it already exists, it forcibly reassigns owner/colony type to the Klingon Empire.
- It also guarantees the system outpost belongs to the Klingon Empire.
- A global flag prevents duplicate executions.

Why this is safer
- It no longer depends on the player choosing the Klingons.
- It no longer depends on a Klingon-only country event being the one that happens to repair the system.
- It no longer depends on the Klingon country already existing on day 0.
- It converts Rura Penthe startup into a global deterministic repair pass executed after startup initialization settles.

Test
1. Full game restart.
2. Start a new game as the Federation.
3. Check Beta Penthe.
4. Confirm Rura Penthe exists as a Klingon colony with a Klingon-owned outpost.
