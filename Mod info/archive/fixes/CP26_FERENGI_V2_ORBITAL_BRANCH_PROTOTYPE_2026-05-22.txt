CP26 Ferengi V2 orbital branch prototype
Date: 2026-05-22

Summary
- Branch implantation now has a visible V2 layer: each Ferengi branch type also
  spawns a dedicated orbital megastructure around the host colony.
- Planet modifiers remain the gameplay anchor for host bonuses and existing
  branch logic.
- Dormancy keeps the orbital structure in place.
- Automatic purge now dismantles the orbital structure and removes the host
  modifier together.
- The planet-view Branches button is now restricted to Ferengi-owned colonies,
  so branch management starts from the Ferengi side instead of foreign worlds.

Files changed
- common/megastructures/cp26_ferengi_branch_hubs.txt
- common/button_effects/cp26_button_effects.txt
- events/cp26_ferengi_branch_events.txt
- localisation/french/cp26_ferengi_branch_l_french.yml
- localisation/english/cp26_ferengi_branch_l_english.yml

Prototype contents
1. New orbital commercial structures
- cp26_ferengi_trade_hub
- cp26_ferengi_mining_hub
- cp26_ferengi_leisure_hub

2. Build flow
- Player branch creation still uses the Ferengi management flow.
- Selecting a branch type now:
  - applies the planet modifier
  - spawns the matching orbital megastructure
  - marks the host planet with a type-specific presence flag

3. AI flow
- The AI Ferengi monthly backend now also spawns the matching orbital
  megastructure when it establishes a branch.

4. Dormancy / purge
- If the pact breaks:
  - branch goes dormant as before
  - orbital structure remains visible during dormancy
- If dormancy expires:
  - host modifier is removed
  - orbital structure is dismantled
  - type-specific planet flag is cleared

5. Repair behavior
- Monthly income processing now respawns a missing orbital structure for active
  branches when the host modifier exists but the orbital presence flag is
  missing. This helps older saves transition into the V2 prototype.
