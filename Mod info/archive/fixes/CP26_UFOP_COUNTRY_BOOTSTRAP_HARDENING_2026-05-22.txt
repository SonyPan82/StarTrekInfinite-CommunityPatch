CP26 UFOP Country Bootstrap Hardening
Date: 2026-05-22

Summary
- Hardened CP26 Federation bootstrap events that assumed `event_target:ufop_country`
  already existed at execution time.
- Replaced fragile trigger checks with `any_country = { has_country_flag = ufop }`
  where appropriate.
- Added local recapture of `ufop_country` in each affected event immediate block via:
  `every_country = { limit = { has_country_flag = ufop } save_global_event_target_as = ufop_country }`

Intent
- Prevent undefined `ufop_country` at game start when Federation-owned colony/bootstrap
  events fire before another path has populated the global event target.

  tied to:
