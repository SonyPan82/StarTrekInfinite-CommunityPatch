Audit CP26 - workflow megastructures, unicite et split Ferengi
Date: 2026-05-22

Objectif
- Verifier que CP26 aligne maintenant les megastructures sur un pipeline plus standard.
- Verifier que la Federation et les Ferengi utilisent des branches distinctes et controlees.

Constats
1. Le tech de base megastructure etait trop limite pour supporter proprement le workflow modde.
2. Le mod workshop apporte son propre pipeline de techs/buildables pour les empires standards.
3. Les Ferengi necessitent une branche separee:
   - buildables reserves
   - prerequis dedies
   - restrictions d'hote specifiques
4. Le Fleet Museum devait etre normalise:
   - Federation seulement
   - un seul exemplaire
   - techno de deblocage dediee

Verification effectuee
- tech_megastructure_1 est donne a tous les empires actifs au demarrage.
- Les buildables workshop standards restent exclus des Ferengi.
- Les buildables Ferengi restent exclus des non-Ferengi.
- Les plateformes Ferengi verifient:
  - proprietaire de systeme hote
  - pacte commercial
  - pas d'autorite corporate
  - 1 plateforme par systeme
  - 3 plateformes par empire hote
- Le Fleet Museum Federation est maintenant borne par un country flag d'unicite.

Risque restant
- Validation en jeu encore necessaire pour confirmer le comportement exact du picker megastructure vanilla sur les plateformes Ferengi chez un hote.
- Le fichier cp26_ferengi_branch_hubs.txt a recu plusieurs passes; une verification runtime reste souhaitable meme si la structure logique est coherente.
