 SECTION 5 — HORS PORTÉE MOD (pour information)
════════════════════════════════════════════════════════════════════════

  Ces HRBTODO ne peuvent pas être corrigés via un mod :

  - HRB_TODO_IMAGE / HRB_TODO_SOUND : assets graphiques/audio manquants
    (nécessitent des fichiers DDS/WAV que seul le développeur peut fournir)

  - HRB_TODO: naval capacity was removed : feature retirée du moteur
    (référencée dans ai_budget, buildings, jobs, traits — sans impact joueur)

  - HRB_TODO dans interface/*.gui/*.gfx : code UI compilé,
    inaccessible par modding standard

  - HRB_TODO dans hornblower_tutorial_events.txt (titres/descs) :
    le tutoriel n'est pas utilisé en partie normale
