Audit CP26 - fusion du mod workshop de megastructures
Date: 2026-05-22

Objectif
- Verifier que le mod workshop 3069363325 est bien integre a CP26 sans donner ses megastructures standards aux Ferengi.

Constats
1. Le mod workshop n'ajoute pas un bouton custom de construction.
2. Son pipeline repose sur:
   - common/megastructures/*
   - common/technology/mm_00_engineering.txt
   - resources.category = megastructures
   - possible = is_inside_border = from
3. Il est donc adapte pour les empires standards construisant chez eux.
4. Il ne fournit pas de solution speciale pour des constructions en espace etranger.

Decision retenue
- Conserver le pipeline workshop pour les empires non ferengi.
- Donner aux Ferengi une ligne separee de megastructures.

Verification effectuee
- tech_mm_mega_aspirations exclut maintenant les Ferengi.
- Les trois megastructures workshop excluent maintenant les Ferengi.
- Les trois megastructures ferengi utilisent maintenant category = megastructures.
- Les prerquis Ferengi passent par une progression technologique propre.

Risque restant
- Les flux UI anciens Ferengi (boutons/events) coexistent encore avec cette V2.
- A terme, un passage de nettoyage UX pourra simplifier tout ca autour du flux final choisi.
