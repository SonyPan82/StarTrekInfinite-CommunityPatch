CP26 - Console de test (trou de ver Bajor + arc Dominion)
===========================================================
Ouvre la console (~), sans ironman. La commande `event <id>` ignore en général
les triggers des événements is_triggered_only.

RÉSUMÉ RAPIDE (copier-coller courant)
-------------------------------------
1) Débloquer l’arc Dominion CP26 (sinon le ticker .1 ne part pas) :
    effect remove_global_flag = cp26_dominion_arc_blocked
2) Forcer la chaîne technique trou de ver (flags + suite .200) :
    event cp26_bajoran_wormhole.900
3) Pop-up « trou de ver confirmé » seul :
    event cp26_bajoran_wormhole.2
4) Marquer ton pays comme découvreur (certaines chaînes le ciblent) :
    effect set_country_flag = wormhole_discoverer

VISUEL TROU DE VER (ambient sur l’étoile Bajor)
-----------------------------------------------
L’ambient `cp26_bajoran_wormhole` est créé dans l’**init_effect** de l’étoile
Bajor (initializer `bajoran_bajor_initializer`) avec l’entité vanilla
`natural_wormhole_entity` (pas de mesh dans le mod CP26). **Nouvelle partie**
obligatoire pour le voir ; une vieille sauvegarde ne régénère pas l’initializer.
Si toujours invisible : vérifier **error.log** (entité absente / conflit mod)
et que le système Bajor est bien celui du initializer (empire Bajor en jeu).

Workflow jouable : les **quatre majors jouables** (UFOP, Klingon, Romulan,
Cardassian) sont en général **contender** : la **première flotte** qui entre dans
le système Bajor (avant découverte) déclenche **.11** → projet **CP26_WORMHOLE_SURVEY**
sur l’étoile Denorios. L’empire **Bajor** sur la carte est en principe **PNJ**
: l’événement annuel **.20** peut lui donner le même projet sur son étoile.

PRÉREQUIS UTILES
----------------
• Désactiver le blocage d’arc au lancement (si tu l’avais laissé actif) :
    effect remove_global_flag = cp26_dominion_arc_blocked
• Te marquer découvreur du trou de ver (pour les chaînes qui ciblent ce pays) :
    effect set_country_flag = wormhole_discoverer
• Flags globaux découverte (souvent déjà posés par .900 / .200) :
    effect add_global_flag = bajoran_wormhole_discovered
    effect add_global_flag = cp26_bajoran_wormhole_bypass_created

TROU DE VER - namespace cp26_bajoran_wormhole
---------------------------------------------
• event cp26_bajoran_wormhole.900   - Active le trou de ver (appelle .200 si pas encore créé)
• event cp26_bajoran_wormhole.901   - Alias : force .200
• event cp26_bajoran_wormhole.200   - Logique hide_window (flags + init DTL Dominion + notif .2)
• event cp26_bajoran_wormhole.2     - Pop-up « trou de ver confirmé actif »
• event cp26_bajoran_wormhole.12    - Notif « relevés anomaux, enquête » (projet CP26_WORMHOLE_SURVEY séparé)
• event cp26_bajoran_wormhole.21    - Notif Bajor 2369 (canon)
• event cp26_bajoran_wormhole.300   - Offre d’expédition Gamma (après phase 1 résolue + cooldown)
• event cp26_bajoran_wormhole.310 / .311 - Branche Gamma « pacifique »
• event cp26_bajoran_wormhole.320 / .321 / .322 - Branche « agressive » / avertissement

Note : .11 est fleet_event (entrée flotte Denorios), pas pratique en console.
