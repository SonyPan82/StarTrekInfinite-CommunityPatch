CP26 - Recent Fixes and Vassalization Notes
Date: 2026-05-06

This file documents the changes made during this session.

1) Ship entity attach point fixes (part1)
----------------------------------------
Goal:
- Resolve runtime errors where ship sizes/sections expected locator "part1"
  but corresponding entities did not expose it.

Applied fixes:
- File: gfx/models/ships/ufop_01/_ufop_01_ships_entities.asset
  - california_entity: part1 locator enabled
  - california_hero_entity: part1 locator enabled
  - sovereign_entity: part1 locator enabled
  - ufop_01_enterprise_sovereign_entity: part1 locator enabled

Notes:
- These are visual/assembly attach-point fixes only.
- No gameplay stats or combat values were changed by these edits.


2) Gorn spawn_system feasibility fix
-----------------------------------
Goal:
- Reduce startup error:
  "spawn_system: found no possible system ... spawn_galdonterre_system"

Applied fix:
- File: common/scripted_effects/aa_gorn_effects.txt
  - spawn_galdonterre_system:
    - max_jumps: 1 -> 2
    - min_distance: 5 -> 3
  - max_distance and hyperlane behavior unchanged.

Result:
- In subsequent relaunch checks, the specific Galdonterre spawn_system error
  no longer appeared.

Follow-up on 2026-05-07:
- File: common/scripted_effects/aa_gorn_effects.txt
  - spawn_gorn_system:
    - min_jumps: 1 -> 3
    - max_jumps: 4 -> 6
    - min_distance: 1 -> 18
    - max_distance: 16 -> 36

Reason:
- The Gorn capital could spawn too close to the Klingon border/Tribble area,
  creating confusing adjacent-but-badly-routed war borders.
- New games should place the Gorn Hegemony a few systems farther away while
  keeping them in the same frontier region.


5) War access and Gorn visibility follow-up
------------------------------------------
Goal:
- Prevent wars from becoming impossible to prosecute because enemy/protector
  borders stay closed.
- Make the Gorn frontier readable for Klingon/Federation/Romulan/Cardassian
  starts instead of leaving some spawned Gorn systems unknown.

Applied fixes:
- Files:
  - events/zz_cp26_war_access_events.txt
  - common/on_actions/zz_cp26_war_access_on_actions.txt
  - common/scripted_effects/aa_gorn_effects.txt
- War participants now force-open borders in both directions.
- War border access refreshes daily while a war is active.
- Neutral zone countries also open to active war participants, so they do not
  trap fleets between belligerents.
- Gorn spawned systems are now surveyed for Gorn, Federation, Klingon,
  Romulan, and Cardassian countries when those countries exist.

Reason:
- In testing, Klingon wars against Gorn and Federation could leave nearby enemy
  systems unreachable because access was only partially refreshed and some
  spawned systems were not known to the player empire.

4) Diplomatic vassalization reactivation (controlled scope)
----------------------------------------------------------
Goal:
- Re-enable a diplomatic path to request vassalization.
- On refusal, attempt to grant a subjugation casus belli.

Applied change:
- File: common/diplomatic_actions/00_hornblower_actions.txt
  - action_offer_membership reactivated and implemented.

Current behavior:
- Actor requirements:
  - default empires only
  - must be major, OR have flag cp26_can_offer_membership_minor
- Recipient requirements:
  - default empire
  - minor only
  - independent
- Action flow:
  - Accept: recipient becomes subject_type = puppet_state of actor
  - Decline: script attempts check_casus_belli_valid for cb_subjugation

Design intent:
- Keep system stable by default (major -> minor only).
- Leave extension path for selected custom minors using:
  - country flag: cp26_can_offer_membership_minor


5) Not changed
--------------
- UFOP/Federation-specific integration process was not modified.
- Existing faction-specific integration/assimilation flows remain unchanged.
