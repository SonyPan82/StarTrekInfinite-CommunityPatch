CP26 - options de début de partie (arcs narratifs)
===============================================

Événement : events/cp26_game_start_options.txt - cp26_options.1

Premier affichage (une fois par campagne) : le bloc immediate pose le
drapeau global cp26_game_start_arc_defaults_v1 puis :
  - cp26_dominion_arc_blocked     (arc Dominion off par défaut)
  - cp26_block_supernova_arc      (branche UFOP Starburst off par défaut)

Le joueur change l’état via les paires de boutons (chaque clic retire ou pose
ces drapeaux selon l’option).

---

Drapeaux globaux :

  cp26_dominion_arc_blocked
    Si posé : le ticker annuel cp26_dominion_threat.1 ne s’exécute pas (trigger),
    et les projets spéciaux Dominion avortent si ce bloc est vrai (abort_trigger).

  cp26_block_supernova_arc
    Si posé : le nœud de quête UFOP qt_ufop_starburst (fichier qt_ufop_d4.txt)
    n’apparaît plus (potential) - la quête Supernova / Hobus n’aura pas lieu.

    Libellés CP26 (popup début) : « quête autorisée » = drapeau absent ;
    « quête bloquée » = drapeau présent. Défaut nouvelle partie : bloqué.

No Supernova (ancien Workshop) : retiré - uniquement CP26 via
cp26_block_supernova_arc sur qt_ufop_starburst (qt_ufop_d4.txt).

Les nœuds Romulans du monolithique vanilla liés aux suspicious_flares ne sont
pas modifiés par CP26 (quest tree éclaté en qt_*.txt).

Dominion : on_actions dans
common/on_actions/zz_cp26_dominion_threat_on_actions.txt ;
trigger .1 ; projets sans « always = yes » dans abort.
