CP26 - Major Factions Technology Tree Lore Plan
Date: 2026-05-26

Goal
- Extend the Federation tech-tree planning pass to Klingon, Romulan, Cardassian, and Ferengi.
- Build a coherent 2346 starting state for every major faction.
- Control both vanilla-like hull techs and custom CP26 ship-class techs.
- Replace random deck noise with faction identity and clean progression.
- Keep special narrative branches separate when they already have bespoke gating.

Scope
- Included:
  - Klingon Empire
  - Romulan Star Empire
  - Cardassian Union
  - Ferengi Alliance
- Excluded from this document:
  - Mars / A500 Federation branch (already separated)
  - Neo-Constitution / Sagan / Duderstadt / Odyssey (already tied to Mars reconstruction)

Shared Principle
- 2346 is not an "early prototype age" for the quadrant majors.
- Major powers should begin with the classes that canonically or thematically already define them.
- Later technologies should feel like real doctrinal evolution, not arbitrary deck outcomes.
- We should use a strict structure:
  - Start package
  - Early expansion wave
  - Mid-era leap
  - Late strategic apex
- If needed, enforce this with:
  - start grants
  - prerequisites
  - year gates
  - weight = 0 before the correct phase


==================================================
1. Klingon Empire
==================================================

Identity
- Aggressive war doctrine
- Disruptors, torpedoes, armor, boarding, assault speed
- Less emphasis on elegant science chains
- Progression should feel like: raiders -> line warships -> heavy battle command ships

Recommended Klingon Start State in 2346

Base hull ladder already known
- tech_corvette_unlock        -> Bird-of-Prey
- tech_destroyer_unlock       -> established Klingon medium warship tier
- tech_cruiser_unlock         -> K't'inga baseline battle cruiser tier

Faction-flavor start techs already fitting the empire
- tech_klingon_shrine
- tech_cloaking_device_1
- tech_enable_automatic_surveying
- tech_civilian_ships

Discussion
- Bird-of-Prey absolutely belongs at start.
- K't'inga should not be a late surprise; by 2346 it is already a defining Klingon battleline class.
- The current mapping "cruiser unlock = K't'inga after 2404" is not usable lore-wise.

Recommended Klingon Linear Ship Progression

START TECHS
- tech_corvette_unlock
- tech_destroyer_unlock
- tech_cruiser_unlock

FIRST RESEARCH WAVE
- tech_cp26_klingon_raptor_unlock
  Role:
  - compact strike destroyer
  Logic:
  - early refinement of raider doctrine

SECOND RESEARCH WAVE
- tech_cp26_kvort_unlock
  Role:
  - fast heavy cruiser / enlarged Bird-of-Prey doctrine
  Logic:
  - step beyond the K't'inga line into a more mobile heavy strike identity

- tech_cp26_kamarag_unlock
  Role:
  - heavier sustained battleline option
  Logic:
  - parallel or slightly after K'vort depending desired bias

THIRD RESEARCH WAVE
- tech_battleship_unlock
  Display identity:
  - Vor'cha
  Role:
  - major modernization of the Klingon fleet core

FOURTH RESEARCH WAVE
- tech_titan_unlock
  Display identity:
  - Negh'Var
  Role:
  - imperial apex / command dreadnought / prestige heavy warship

Strict Blocking Recommendation

Start package
- tech_corvette_unlock
- tech_destroyer_unlock
- tech_cruiser_unlock

Then:
- tech_cp26_klingon_raptor_unlock
  requires:
  - tech_destroyer_unlock

- tech_cp26_kvort_unlock
  requires:
  - tech_cruiser_unlock
  - optional year gate after early start phase

- tech_cp26_kamarag_unlock
  requires:
  - tech_cruiser_unlock
  - optional tech_cp26_kvort_unlock OR same phase parallel branch

- tech_battleship_unlock (Vor'cha)
  requires:
  - tech_cruiser_unlock
  - tech_cp26_kvort_unlock
  - tech_cp26_kamarag_unlock optional but recommended if you want a tighter military ladder

- tech_titan_unlock (Negh'Var)
  requires:
  - tech_battleship_unlock
  - late military maturity gate

Recommended Tech Flavor Bias
- Strong weight:
  - disruptor weapons
  - torpedoes
  - hull / armor
  - boarding / troop projection
  - command doctrines / military efficiency
- Lower weight:
  - pure civilian optimization
  - high-end exploratory science
  - fragile long-range precision chains

6. Implementation Philosophy
==================================================

To make the game coherent, we should treat faction trees with the same logic used for the Federation plan:

- Some classes are not "future discoveries" in 2346 and must be granted at start.
- The vanilla hull ladder should become a progression backbone, not a random naming mess.
- Custom classes should appear in deliberate eras and doctrinal phases.
- Faction signature mechanics should be in the tree early enough to define playstyle.

Recommended enforcement tools
- give_technology at game start for already-existing classes
- strict prerequisites
- year gates only where truly needed
- weight = 0 before intended phase
- narrative branches kept separate where they already exist (Mars / Bajor / similar)

7. Semi-Linear Very Controlled Model
==================================================

Definition
- We do NOT want a totally open deck.
- We do NOT want a single hard corridor with no variation.
- We want a controlled structure:
  - one mandatory trunk
  - one or two side branches maximum per era
  - no major leap allowed before the previous trunk step is complete

In practice
- A faction always has:
  - a trunk tech
  - maybe one military side tech
  - maybe one support/specialization side tech
- Everything else should stay:
  - blocked
  - or at extremely low weight

Why this is the right model for CP26
- It keeps the game readable.
- It preserves faction identity.
- It avoids absurd lore order.
- It still leaves a little flexibility for replayability.

Per-faction implementation model

Federation
- Trunk:
  - New Orleans -> Nebula -> Galaxy -> Luna -> Sovereign
- Side branches:
  - Akira
  - California
- Rule:
  - Sovereign never before Galaxy
  - Luna never before Galaxy
  - California never before late institutional phase

Klingon
- Trunk:
  - K't'inga baseline -> K'vort/Kamarag phase -> Vor'cha -> Negh'Var
- Side branch:
  - Raptor
- Rule:
  - Vor'cha never before the heavy cruiser phase is complete
  - Negh'Var always last major military leap

Romulan
- Trunk:
  - Singularity 1 -> Singularity 2 -> Valdore -> Singularity 3 -> D'Deridex -> Majestus
- Side branch:
  - cloak / espionage maturation
- Rule:
  - D'Deridex must feel like the first huge strategic warbird jump
  - Majestus remains the apex

Cardassian
- Trunk:
  - Hideki/Galor baseline -> Keldon -> Kazikai -> Nokoram
- Side branch:
  - infrastructure / command improvements
- Rule:
  - Galor is already normal in 2346
  - Keldon is the modernization step

Ferengi
- Trunk:
  - D'Kora baseline -> Mining Platforms -> Quark Platforms
- Side branch:
  - larger combat hull progression if desired
- Rule:
  - Ferengi economic identity must mature before any true military apex

8. Rules For Adding New Ship Classes Or Technologies
==================================================

Whenever a new class or technology is added, use this checklist.

Step 1 - Identify the role
- Ask:
  - Is it a baseline ship?
  - A modernization step?
  - A side-grade specialization?
  - A late prestige flagship?
  - A narrative unlock?

If the answer is unclear, do not add it yet.

Step 2 - Place it in one of 5 buckets
- Start package
- Early expansion wave
- Mid-era leap
- Late strategic apex
- Narrative branch only

Every new class must belong to exactly one bucket.

Step 3 - Decide trunk or branch
- Trunk classes:
  - define the military identity of the era
  - must gate later major ships
- Branch classes:
  - are optional side specializations
  - must never bypass the trunk

Hard rule
- A branch may enrich the era.
- A branch must never replace the trunk.

Step 4 - Define prerequisites
- Use one of these patterns:

Pattern A - direct trunk continuation
- tech_A -> tech_B -> tech_C

Pattern B - branch off a trunk point
- tech_A -> tech_B
- tech_B -> tech_B_side_1
- tech_B -> tech_B_side_2
- tech_C still requires tech_B, not the side branch

Pattern C - narrative lock
- tech_X is invisible or weight 0 until:
  - event flag
  - mission completed
  - arc outcome

Step 5 - Decide if it already exists in 2346
- If yes:
  - grant it at start
  - do NOT put it in the random research deck
- If no:
  - place it in the correct era
  - then gate it normally

This rule matters a lot.
- Never make an already-common 2346 class look like a revolutionary future invention.

Step 6 - Give it faction flavor
- New classes should reinforce, not blur, the empire identity:

Federation
- exploration
- balanced fleets
- shields/sensors/phasers

Klingon
- assault
- armor/hull
- disruptor and heavy combat

Romulan
- stealth
- singularity
- intelligence and precision

Cardassian
- control
- command
- infrastructure and occupation

Ferengi
- commerce
- extraction
- leverage and practical deterrence

Step 7 - Keep the deck small
- In each era:
  - maximum 1 trunk unlock
  - maximum 1 or 2 branch unlocks
- If there are more, the tree becomes noisy again.

Step 8 - Use year gates only as support
- Year gates should smooth timing.
- They should not be the main logic.
- The main logic must remain:
  - role
  - prerequisites
  - faction identity

Good use of year gates
- prevent a late prestige ship from appearing absurdly early

Bad use of year gates
- use dates alone to fake a structure that has no coherent prerequisite chain


==================================================
9. Golden Rule Summary
==================================================

When adding a new class or technology:

1. decide what role it has
2. decide if it already exists in 2346
3. place it in a single era bucket
4. make it trunk or branch
5. ensure it cannot skip the trunk
6. align it with faction identity
7. keep the deck narrow

If we follow that, the tech tree stays coherent even as CP26 grows.

10. Implemented Visible Side Branches
==================================================

This pass adds one visible late branch for three major factions that were still under-served compared to Federation content.

Klingon
- Main trunk remains:
  - Bird of Prey -> Warbird -> K't'inga -> Vor'cha -> Negh'Var
- Side branch kept:
  - Raptor
  - K'vort
  - Kamarag
- New visible late branch:
  - Jach battlecruiser
- Placement rule:
  - after battleship access
  - after Kamarag branch
  - below Negh'Var

Romulan
- Main trunk remains:
  - Ferrax -> Vindius -> Valdore -> D'Deridex -> Majestus
- New visible late branch:
  - Praetor warbird
- Placement rule:
  - after battleship access
  - after artificial singularities tier 3
  - below Majestus
- Reserved for later:
  - Scimitar remains mission-tree content, not standard deck research

Cardassian
- Main trunk remains:
  - Hideki -> Galor -> Keldon -> Kazikai -> Nokoram
- New visible late branch:
  - Hutet dreadnought
- Placement rule:
  - after battleship access
  - below Nokoram
  - visible as a prestige heavy hull, not a titan replacement

Why this is the right scale
- It gives each faction one extra visible military aspiration.
- It does not explode the deck with too many side hulls at the same era.
- It preserves the existing apex classes:
  - Negh'Var
  - Majestus
  - Nokoram
