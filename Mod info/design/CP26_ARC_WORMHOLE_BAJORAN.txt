# CP26 — Implémenté le 2026-05-29

DESCRIPTION
-----------
Arc narratif multi-factions déclenché automatiquement 1 an après la fin
de l'arc de libération de Bajor (qu'importe l'issue : Bajor libre ou
toujours occupé).

Chaque grande puissance reçoit un event "Anomalie dans la Ceinture
Denorios" avec des options spécifiques à son identité lore. Si le joueur
envoie un vaisseau, un projet spécial de 360 jours s'ouvre dans le
journal de bord. À la complétion, le trou de ver Bajoran apparaît dans
le système Bajoran.


DÉCLENCHEMENT
-------------
Global flag requis pour que le Bajor arc puisse se déclencher :
  cp26_bajor_arc_initialized  (posé au démarrage si Bajor arc activé)

L'arc wormhole se déclenche 365 jours après la fin de l'arc Bajor.
Les points terminaux qui posent le flag de queue :
  - cp26_bajor.52 (UFOP libère Bajor via troupes)
  - cp26_bajor.10 (libération diplomatique/militaire)
  - cp26_bajor.33 (Bajor se libère seule — notification)
  - cp26_bajor.34 (Cardassia écrase la rébellion — notification)


FACTIONS ET OPTIONS
-------------------

  UFOP (Fédération)
    A. Envoyer un vaisseau scientifique → projet CP26_BAJORAN_WORMHOLE_SURVEY_UFOP
    B. Ne rien faire → aucun projet, pas de découverte

  KLINGON
    A. Corps expéditionnaire (science + militaire) → CP26_BAJORAN_WORMHOLE_SURVEY_KLINGON
    B. Ne rien faire

  CARDASSIEN
    A. Vaisseau scientifique → CP26_BAJORAN_WORMHOLE_SURVEY_CARDASSIAN_SCIENCE
       ⚠ Grisé si Bajor est libéré ET frontière fermée avec les Bajorans
    B. Vaisseau espion → CP26_BAJORAN_WORMHOLE_SURVEY_CARDASSIAN_SPY
       (toujours disponible)
    C. Ne rien faire

  ROMULIEN
    A. Vaisseau espion (Tal Shiar) → CP26_BAJORAN_WORMHOLE_SURVEY_ROMULAN
    B. Ne rien faire

  FERENGI
    A. Prospecteur (science ship) → CP26_BAJORAN_WORMHOLE_SURVEY_FERENGI
    B. Colonie de touristes → +1000 énergie immédiat + découverte après 360j
    C. Ne rien faire


PROJETS SPÉCIAUX (360 jours)
-----------------------------
Tous les projets se trouvent dans :
  common/special_projects/cp26_bajoran_wormhole_projects.txt

  CP26_BAJORAN_WORMHOLE_SURVEY_UFOP             science ship
  CP26_BAJORAN_WORMHOLE_SURVEY_KLINGON          science ship + military
  CP26_BAJORAN_WORMHOLE_SURVEY_CARDASSIAN_SCIENCE  science ship
  CP26_BAJORAN_WORMHOLE_SURVEY_CARDASSIAN_SPY   spy ship
  CP26_BAJORAN_WORMHOLE_SURVEY_ROMULAN          spy ship
  CP26_BAJORAN_WORMHOLE_SURVEY_FERENGI          science ship

Journal de bord actif pendant toute la durée du projet.
Event chain : cp26_bajoran_wormhole_chain


DÉCOUVERTE (cp26_bajoran_wormhole.100)
--------------------------------------
La popup finale apparaît pour chaque faction ayant envoyé un vaisseau.
Le trou de ver est spawné une seule fois (global flag cp26_bajoran_wormhole_spawned)
dans le système Bajoran via spawn_natural_wormhole.

Options par faction :
  UFOP       : "Extraordinaire / Restons prudents."
  Klingon    : "Une porte vers Sto-vo-kor ! / Cela ne nous regarde pas."
  Cardassien : "Intéressant. Reprendre Bajor. / Surveiller de loin."
  Romulien   : "Étudier cela de près. / Cela occupera la Fédération."
  Ferengi    : "Nouveau monde d'opportunités ! / Étudier un péage."

FLAGS
-----
  cp26_bajoran_wormhole_queued      (country) — empêche double-déclenchement
  cp26_bajoran_wormhole_dispatched  (country) — event .0 exécuté
  cp26_bajoran_wormhole_discovered  (country) — découverte reçue
  cp26_bajoran_wormhole_spawned     (global)  — trou de ver déjà créé


CHEATCODES — CONSOLE
--------------------

# ── Test complet depuis zéro (simuler fin de l'arc Bajor) ─────────────

# Poser le flag de queue et déclencher immédiatement l'event faction
effect = { set_country_flag = cp26_bajoran_wormhole_queued country_event = { id = cp26_bajoran_wormhole.0 } }

# ── Sauter directement à chaque event faction ─────────────────────────
event cp26_bajoran_wormhole.10    # UFOP
event cp26_bajoran_wormhole.20    # Klingon
event cp26_bajoran_wormhole.30    # Cardassien
event cp26_bajoran_wormhole.40    # Romulien
event cp26_bajoran_wormhole.50    # Ferengi

# ── Sauter directement à la découverte (bypass projet) ───────────────
event cp26_bajoran_wormhole.100

# ── Tester le spawn du trou de ver seul ──────────────────────────────
effect = { random_galaxy_planet = { limit = { has_planet_flag = planet_bajor } solar_system = { spawn_natural_wormhole = { bypass_type = wormhole random_pos = yes } } } }

# ── Reset complet de l'arc (pour retester) ───────────────────────────
effect = {
  remove_country_flag = cp26_bajoran_wormhole_queued
  remove_country_flag = cp26_bajoran_wormhole_dispatched
  remove_country_flag = cp26_bajoran_wormhole_discovered
  remove_global_flag  = cp26_bajoran_wormhole_spawned
}

# ── Simuler fin d'arc Bajor (pour déclencher le timer 365j) ──────────
effect = { set_global_flag = cp26_bajor_liberated set_country_flag = cp26_bajoran_wormhole_queued country_event = { id = cp26_bajoran_wormhole.0 days = 1 } }


NOTES DE DÉVELOPPEMENT
-----------------------
- spawn_natural_wormhole est un effet Stellaris vanilla hérité par Infinite.
  À TESTER : vérifier que l'effet est bien supporté dans la version actuelle
  d'Infinite. Si non supporté, remplacer par un ambient_object avec entité
  wormhole ou utiliser un flag uniquement (sans objet visuel).

- Le trou de ver spawné est un wormhole "naturel" standard — il n'est pas
  lié à une destination (Gamma Quadrant non scripté dans Infinite vanilla).
  Une suite narrative peut être ajoutée ultérieurement (arc Dominion).

- La localisation de cp26_bajoran_wormhole.55 (timer touriste Ferengi)
  n'est pas nécessaire car l'event est hide_window = yes.
