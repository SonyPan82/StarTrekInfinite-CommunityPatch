# CP26 - Star Trek lore-faithful personalities for the 4 major empires.
#
# These personalities override the vanilla ethics-based personality selection
# by using weight_modifier = 1000 (vanilla majors are typically at weight 50).
# Targeted via has_country_id, so they only activate for the canonical empire.
#
# Tuning principles :
#   - aggressiveness  : how often they declare wars + how much power committed
#                       (0 = 50% committed, 1 = 75%, 2 = 100%)
#   - bravery         : are they willing to attack stronger neighbours
#   - combat_bravery  : how long they stay in a fight before disengaging
#   - weapon_preferences / *_ratio : enforces lore weapon types and ship fit
