# CP26 - Minor Species Traits
# ============================================================
# 60 species traits for the 20 prescripted minor factions.
# Each race gets 3 unique lore-driven traits.
#
# Naming follows the conventions already referenced in
# prescripted_countries/00_*.txt (no rename needed).
#
# Structure :
#   - 18 traits HRB_DIPLO : Bajoran, Betazoid, Iyaaran, Kaelon, Malcorian, Trill
#   - 18 traits HRB_TRADE : Bolian, Boslic, Farian, Hupyrian, Lissepian, Pelian
#   - 21 traits HRB_HARDY : Acamarian, Cairn, Idanian, Kesprytt, Ktarian, Talarian, Tanugan
#   -  3 traits JNA       : Jnaii
#
# Design budget per race : ~+3 to +5 total cost (light "above vanilla" tilt
# fitting their bespoke/prescripted status). Most positives are cost=2 with
# a flagship trait at cost=4 ; each race has one cost=-1 cultural drawback.
#
# Modifiers used are all visible in existing CP26 / vanilla STI trait files
# (aa_tholian_traits, denobulan_traits, remus_traits, risan_traits,
# 00_hornblower_leader_traits).

# ============================================================
# HRB_DIPLO - Diplomatic / Empathic minors
