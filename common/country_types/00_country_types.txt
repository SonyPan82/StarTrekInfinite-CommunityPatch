		# CP26 — Dynamic ship_data scaling
		#
		# Vanilla used hard-coded min/max for constructor/science/colonizer,
		# which left late-game AIs under-staffed once their empire grew.
		#
		# The cp26_empire_size_* country flags are updated yearly by event
		# cp26_ai_pulse.1 (events/zz_cp26_ai_pulse_events.txt) based on
		# count_owned_planet :
		#   small  : 0 - 3
		#   medium : 4 - 7
		#   large  : 8 - 14
		#   huge   : 15+
		#
		# Each ship category below uses these flags as fraction modifiers,
		# growing the AI's construction priorities as its empire scales.
		#
		# CP26 2026-05-14 (fourth pass) : strict cap 21 ships/empire.
		# `default` n'existe plus qu'une fois (fusion 00_country_types) — plus de merge moteur.
		# Constructor : 2/2 (aligné contender).
		#
		# Budget indicatif civils (IA default, plafonds ship_data) :
		#   2 const + 2 sci + jusqu'à 2 col = 6 civils
		#   + 15 militaires (caps count_owned_ship + factor=0 ailleurs)
		#
		# Historique :
		#   - Vanilla CP26 initial      : 3/6 + 3/5 + 0/6 = jusqu'à 17 civils
		#   - Second pass (alignement)  : 1/2 + 2/2 + 0/2 = 6 civils max
		#   - Third pass (23 ships)     : 1/3 + 2/3 + 0/2 = 8 civils max
		#   - Fourth pass (21 strict)   : 1/1 + 2/3 + 0/2 = 6 civils max
		#   - Fifth pass (sci spam fix) : 1/1 + 1/2 + 0/2 = 5 civils max
		#   - Sixth pass                : 2/2 const ; colonizer 00 aligné sur zz
