# Community Patch 2026 - Star Trek: Infinite

Community Patch 2026 is an actively maintained community overhaul for **Star Trek: Infinite**.

It brings together bug fixes, stability improvements, balance changes, restored content, and integrated community additions into a single package designed to make campaigns feel more coherent, more complete, and more enjoyable over time.

---

## Main Features

- Integration or restoration of several factions, secondary empires, and additional colonies
- New ship classes, shipsets, visual variants, and fleet-related content
- Restored, expanded, or reworked diplomatic options
- Additional campaign settings, start events, and narrative arcs
- Fixes for galaxy generation, scripts, general stability, and many inconsistencies in the base game
- A range of balance changes aimed at improving pacing, clarity, and overall cohesion

---

## What CP26 Adds Over Vanilla

- New factions integrated into the galaxy, including **Ferengi, Gorn, Orion, Tholian**, and other secondary content
- Additional or restored **colonies and systems** for major powers and minor factions
- New **ship classes, shipsets, global designs, and visual variants** for several empires
- Expanded diplomacy with restored **vassalization, subjugation wars, and additional interactions**
- Reworked **AI, personalities, campaign starts, and overall balance**
- Extended **events, narrative arcs, quest content, and game-start options**
- Expanded **music, interface, and presentation** for a more complete campaign experience

---

## Mod Goal

The goal of CP26 is straightforward: to offer a more stable, more complete, and more Star Trek-faithful experience while staying close to the structure of the vanilla game and preserving as much of its identity as possible.

---

## Installation

Enable **only Community Patch 2026** in the launcher.
Do **not** enable included or integrated source mods separately.

Recommended setup:

- **Star Trek: Infinite 1.0.7**
- **CP26 only**

## Install From GitHub

If you want to use the GitHub version instead of Workshop:

1. Download the repository as a `.zip`, or clone it with Git.
2. Extract or copy the folder into your local mod directory:

   **macOS**
   `~/Documents/Paradox Interactive/Infinite/mod/`

   **Windows**
   `Documents\Paradox Interactive\Infinite\mod\`

3. Make sure the mod folder is named clearly, for example:

   `CP26`

4. Make sure the corresponding `.mod` descriptor points to that local folder.
5. Launch the Paradox launcher and enable the local version of **Community Patch 2026**.
6. Disable the Workshop version if both are present, to avoid conflicts.

### Simple Activation Check

Once the mod is enabled, verify that:

- the launcher shows **Community Patch 2026**
- only one CP26 entry is enabled
- no integrated source mods are enabled alongside it
